# 版本发布记录

GoWind Admin 保持**约每周一切版**的迭代节奏：每个周一从主干切出一个新版本，快速交付功能并对齐文档。本文按版本倒序整理各版本的主题要点，帮助你快速了解项目演进脉络。

- 首个正式版本：**v1.0.0**（09-24）
- 当前最新正式版本：**v1.5.0**（10-29）
- 已合并但尚未发版的内容归入 **Unreleased** 小节

::: tip
升级前建议通读相邻两个版本的变化点，确认自己使用到的模块是否受影响。源码仓库（GitHub / Gitee / AtomGit 镜像，`tx7do/go-wind-admin`）内可查看每个版本对应的完整代码变更。
:::

## v1.5.0（10-29）

主题：**BI 仪表盘 + 打印模板**，补齐数据展示与单据输出两大能力。

### BI 仪表盘全栈

- 可视化拖拽画布，自由搭建仪表盘布局
- 支持跨图联动：一张图表的筛选可驱动整页图表刷新
- 支持数据下钻，从汇总数字逐层深入明细
- 内置 9 套主题，适配不同的展示场景

### 打印模板模块

- 可视化拖拽设计打印模板，业务人员也能自助调整单据版式
- 支持行打印与批量打印，适配票据、清单等场景
- 服务端 PDF 渲染（基于 chromedp），导出结果与浏览器无关、版式稳定
- 内置 A4、A5 及工牌种子模板，开箱即用

## v1.4.0

主题：**AI Agent 编排 + 通知能力扩展**。

### AI Agent 编排全栈

- 图 DSL：以五种节点描述 Agent 编排流程
- 可视化画布：拖拽编排，流程一目了然
- 试运行支持 SSE 实时输出，编排结果即时验证

### 通知渠道扩展

- 扩展渠道增至 **39 个**，覆盖主流消息触达平台
- 新增阿里云短信、腾讯云短信渠道

### 账号安全

- 支持手机号找回密码

## v1.3.0

主题：**工作台聚合页三端同构**。

- 工作台聚合页在 React、Vue Element、Vue Vben 三套前端中保持同构实现
- 三端用户看到一致的工作台布局与信息结构，切换前端实现没有学习成本

## v1.2.0

主题：**企业级身份与合规能力**，面向对外交付与企业内网场景补齐短板。

### 企业 OIDC SSO

- 支持企业 OIDC 单点登录，已通过 Keycloak 实测
- 企业用户可直接接入已有身份体系，无需重建账号

### 通知域 P3 收官

- 通知域三期规划收官，通知相关能力完整闭环

### 合规与配额

- 审计日志支持服务端流式导出，可突破常规列表导出的行数上限
- 套餐配额硬执行：超限操作被直接拦截，配额不再只是"记录"

### 租户与 AI

- 租户白标：租户级品牌定制
- AI Function Call：AI 可调用系统内函数，从"能聊"走向"能办事"

## v1.1.0

主题：**AI 模块全栈落地**。

- AI 对话模块全栈接入：SSE 流式对话输出，配套配额管理
- 知识库 RAG：基于 pgvector 的向量检索，让 AI 回答有据可依
- 智能问数：用自然语言查询业务数据
- AI 内容生成：辅助撰写业务内容
- 全局语义搜索：跨模块的语义检索入口

## v1.0.0（09-24）

首个正式版本，确立三端同构 + 单体后端的基础形态。

### 脚本系统

- 内置 Lua + JavaScript 脚本引擎
- 无需重新编译即可扩展业务逻辑，适合轻量定制场景

### 设计语言规范

- 发布设计语言规范，统一三端视觉与交互基线

### 在线用户

- 在线用户会话管理，实时掌握当前登录情况

## Unreleased（开发中）

### 测试与稳定性

- 后端单元测试第二轮大补：新增约 200 个单元测试
- 修复 8 处生产缺陷，稳定性进一步提升
