# GoWind CRM

GoWind CRM 是一款**私有化部署友好的企业级 B2B 销售 CRM**：以「线索 → 客户 → 商机 → 报价 → 合同 → 回款」为主线，把获客、客户经营、销售推进与回款管理收进同一个平台；组织权限、审批流、数据权限与审计合规等企业底座开箱即用，销售数据全部留在企业自有环境。

::: tip 本页适合谁读
- **销售管理者**：了解从获客到回款的完整销售闭环如何在一个平台里管起来；
- **信息化负责人**：评估私有化交付、数据权限与审计合规能力；
- **售前 / 实施顾问**：快速掌握产品全貌与交付口径。
:::

## 一、核心亮点

### 1. 获客与线索

- **询盘邮箱接入**：绑定 IMAP 询盘邮箱，新邮件自动拉取、智能解析、自动建档为线索，查重后分发跟踪——外贸获客入口全自动；
- **线索全流程**：录入、转换、分配、转移、释放完整闭环，沉淀客户不流失；
- **营销自动化**：规则驱动的自动化动作（手动 / 触发执行），重复跟进不再靠人肉。

### 2. 客户与公海

- **客户与联系人**：客户共享、交接、查重、列配置一应俱全；
- **公海池**：多公海池按规则自动回收与分配，领取保护期防止抢单，沉淀客户激活再利用；
- **跟进日历**：跟进记录全量留痕，日历视图让每个人的拜访与联络日程一目了然。

### 3. 商机推进

- **商机看板**：全生命周期可视推进，赢单走送审确认；
- **阶段自定义**：销售阶段按企业自身打单流程自由配置；
- **加权预测**：按阶段赢率加权预测业绩，管道健康度提前预警。

### 4. 报价、合同与回款

- **报价单**：产品行项报价、送审流转、打印与 PDF 导出，客户单据直接交付；
- **合同管理**：合同模板、送审闭环、到期提醒；
- **回款管理**：收款计划、回款记录、逾期台账、加权预测与对账导出，回款风险早发现。

### 5. 企业底座

- **审批流引擎**：报价、商机赢单、合同送审等业务单据审批闭环；
- **数据权限**：策略引擎按角色 / 部门 / 个人控制数据可见范围，评估过程全程留痕；
- **自定义字段**：客户 / 线索 / 商机支持扩展属性，适配个性化业务口径；
- **绩效目标**：销售目标逐级拆解，进度实时跟踪；
- **售后工单**：派单、处理、回访闭环，服务与销售衔接；
- **报表分析**：概览 / 漏斗 / 趋势 / 排行四大维度，支持 xlsx 导出；
- **开放联动**：Webhook 出站订阅业务事件，与外部系统联动。

### 6. 安全与合规

- **五类审计日志**：API、操作、登录、数据访问、权限变更全量留痕；
- **账号安全**：MFA 双因素、OAuth、登录策略与登录审计；
- **多租户与多语言**：多租户隔离、中英双语界面，一套系统服务多主体。

## 四、适用场景

### 外贸获客到成交

询盘邮箱自动建档 → 线索分发跟进 → 客户转化 → 商机推进 → 报价合同送审 → 回款收口——外贸销售全链路一条线跑通。

### B2B 销售团队管理

公海规则回收激活沉淀客户；销售目标逐级拆解到人；加权预测让业绩早知道；概览 / 漏斗 / 排行报表一页看全。

### 数据合规与私有化

全平台私有化部署，销售数据不出企业内网；数据权限策略 + 五类审计日志满足内控与合规审查。

## 五、技术栈与部署

后端基于 go-kratos 微服务框架构建（后台 BFF / 前台 BFF / 核心业务三服务架构），Protobuf 契约先行，Ent ORM；
前端为 Vue3 + TypeScript（Vben Admin monorepo）；本地与生产均可用 Docker Compose 一键拉起依赖。

| 组件 | 说明 |
| --- | --- |
| 后端 | go-kratos + Ent + PostgreSQL / MySQL，三服务微服务架构 |
| 前端 | Vue3 + TypeScript（Vben Admin） |
| 基础设施 | Redis、S3 兼容对象存储、etcd、OpenTelemetry、Asynq |
| 部署 | Docker Compose 一键启动依赖，支持私有化二进制交付 |

## 六、版本与路线

一期 MVP（线索、客户与公海、商机看板、跟进、报表、数据权限、审批）与二期（报价、合同、回款、绩效目标、售后工单）能力均已上线；
三期规划：AI 线索打分、销售预测、PaaS 自定义对象、BI 大屏、IM 深度联动。
