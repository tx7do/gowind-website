# 学生端功能指南

学生端提供**微信小程序**与 **H5** 两种形态，注册登录后即可使用。页面底部固定五个标签：**首页、练习、复习、错题本、我的**，分别对应今日任务、开始练习、复习计划、错题管理与个人学情。

本指南按一次真实的学习旅程组织：注册进入 → 今日任务 → 练习 → 答题与防作弊 → 错题本 → 复习计划 → 考后讲评 → 学情报告 → 成长中心 → AI 家教 → 作业与收藏笔记 → 微信提醒与家长可见。

::: tip 账号说明
学生账号支持**自助注册**：系统部署后由学校/机构公布访问地址，学生通过该地址进入并注册登录，再使用班级加入码加入对应班级。教师账号由管理员统一创建，学生无需关心。
:::

## 一、注册登录与今日任务

完成注册登录后，首页就是「今日任务」，它是学生每天学习的入口：

- **打卡连续天数**：记录连续学习天数，帮助养成每天学一点的习惯；
- **本周目标进度环**：自己设定本周答题目标（10-500 题），进度实时可见，把大目标拆成一周一周的小步子；
- **待办聚合**：把今天必须处理的事情集中到一页，包括——
  - **到期复习**：今天到期的复习任务；
  - **待交作业**：即将截止的作业；
  - **薄弱点推荐**：根据作答数据推荐今天值得练的薄弱知识点；
  - **进行中的课堂快测**：老师发起课堂快测时，首页会出现带倒计时的卡片，点击立即进入（限时且只能做一次）。

学生每天打开首页就能知道「今天该做什么」，不需要在各个功能之间来回寻找。

## 二、开始练习

「练习」标签页提供两种练习入口：

| 入口 | 选题方式 | 适合场景 |
|------|----------|----------|
| 智能练习 | 按薄弱知识点自动选题 | 日常巩固，不知道该练什么时 |
| 专项练习 | 自选学科、知识点、题量、题型 | 针对性突破某个知识点或题型 |

无论从哪个入口进入，都可以选择五种答题模式：

| 模式 | 说明 | 适合场景 |
|------|------|----------|
| 练习模式 | 边做边学，客观题即时判分 | 日常刷题、课后巩固 |
| 考试模式 | 计时作答，倒计时结束自动交卷 | 模拟考试、检验真实水平 |
| 错题重做 | 重做错题本里的题目 | 消灭错题 |
| 复习模式 | 完成复习计划中到期的题目 | 按遗忘曲线科学复习 |
| 变式训练 | 完成 AI 生成的错题变式题 | 举一反三，防止「背答案」 |

::: tip 薄弱知识点是怎么来的
「薄弱知识点」来自你的历次作答统计：某个知识点错得越多，越容易被智能练习选中。坚持完成推荐的练习，薄弱点会逐步被消除，系统也会越来越少推荐它们。
:::

## 三、答题与防作弊

答题过程中的关键机制：

- **客观题即时判分**：选择、判断等客观题提交后立即出分，马上知道对错；
- **主观题 AI 批改**：解答、作文等主观题由 AI 异步批改，出分后附有评语，可对照评语自评；
- **拍照作答**：简答、作文等主观题可以直接打字，也可以拍照上传（最多 3 张），AI 按图片内容批改——手写演算和作文都能交；
- **逐段批注**：AI 批改主观题时会引用你的原文逐段点评——哪段写得好、哪里有问题，像老师在卷面上划线批注；
- **讲解视频**：老师给题目挂了讲解视频时，解析区下方即可直接观看；
- **作答用时**：每道题的作答用时逐题可见，答得过快自己也能察觉；
- **考试倒计时**：考试模式下页面显示倒计时，时间一到自动交卷，不用担心忘点提交；
- **排行榜**：开启排名的试卷考试会生成排行榜，可以看到自己在班级中的位置。

::: warning 考试请认真独立作答
考试模式下，系统会对**题目与选项乱序**排列，每位同学看到的顺序都可能不同；**切出页面的次数会被记录**，教师可以在后台看到每个人的切屏次数，异常时会收到预警。请像对待真实考试一样独立完成作答。
:::

试卷类考试还可能带有教师设置的控制项：**限次**（只能作答几次）、**限时**（单次时长限制）、**时间窗**（只能在指定时间段进入）。进入考试前请留意考试说明，确认自己处于合适的环境与时间。

## 四、错题本：把每一道错题消灭掉

底部标签「错题本」是学生端最有价值的模块之一：

| 能力 | 说明 |
|------|------|
| 自动归集 | 做错的题自动进入错题本，不需要手动整理 |
| 重复做错累加 | 同一道题反复做错会累加记录，提醒你它有多顽固 |
| 错因标记 | 做错时 AI 自动推断错因帮你填好（概念不清、计算失误、审题错误等），觉得不准可以手动修改，你的标记永远优先 |
| 拍题录错题 | 校外的纸质错题拍张照，AI 自动识别录入你的错题本并生成复习计划，校外错题也进入统一的复习节奏 |
| 相似题推荐 | 自动推荐与错题相似的题目，把一个知识点练透 |
| AI 变式训练 | 让 AI 基于错题生成变式题；变式题按学生私有隔离，互不影响 |
| 按知识点筛选 | 错题本可按知识点过滤，集中攻克某一类题 |
| 错题汇编册 | 全部未掌握错题按错因分组排成打印版，考前一键打印集中攻克 |
| 题目纠错 | 发现题目本身有问题可一键报错给老师，处理后会收到通知 |
| 已掌握移出 | 真正掌握后可移出错题本，让错题本始终保持「待消灭」状态 |

::: tip 错题本的最佳用法
每周固定做一次「错题重做」：先看错因标记，再重做题目，最后用「变式训练」确认自己是真的会了，而不是记住了答案。已经稳定做对的题及时移出，错题本越短，复习效率越高。
:::

## 五、复习计划：让遗忘曲线为你工作

### 原理：家长也能看懂的艾宾浩斯 + SM-2

心理学上有一个著名的「**艾宾浩斯遗忘曲线**」：学过的知识如果不复习，会先快后慢地遗忘——头一两天忘掉一大半，之后遗忘速度逐渐放缓。对抗遗忘最有效的办法，就是在快要忘记的时间点及时复习，并且让两次复习的间隔越拉越长。

GoWind Edu 的复习计划正是按这个规律自动运转的：

1. **自动生成**：错题会自动生成一份基于艾宾浩斯遗忘曲线的复习计划，不需要学生或家长自己安排；
2. **SM-2 自适应间隔**：每次复习由 SM-2 算法决定下一次时间——这道题**答对了**，说明记得比较牢，下次复习间隔会**拉长**；**答错了**，说明还没记牢，间隔会**缩短**、更快安排重练。每个学生对每道题的复习节奏都是独一无二的；
3. **到期提醒**：复习任务到期时通过站内信提醒，开启微信提醒后还会直接推送到微信，不会遗漏；
4. **7 天复习日历**：「复习」标签页提供未来 7 天的复习日历，一眼看清每天有多少复习任务；
5. **复习统计**：复习页顶部实时显示复习完成率（总数/已完成/待复习/已过期）与累计复习用时。

::: tip 给家长的话
复习计划不需要额外监督：孩子完成当天的复习任务后，系统会自动安排下一次复习时间。您只需要关注两件事——「复习」页里到期的任务有没有清零，以及「我的」页里的连续打卡天数是否稳定。
:::

## 六、考后讲评：AI 帮你复盘整张试卷

参加试卷考试后，除了成绩与排行榜，还能获得**考后讲评**：

- **AI 整卷点评**：AI 通读整张答卷，给出整体点评；
- **失分归纳**：按知识点与题型归纳丢分集中在哪里；
- **练习建议**：给出后续练习建议，并可**一键生成练习卷**，针对失分点立刻开始补练。

一次考试以「考试 → 讲评 → 补练」的完整闭环结束，而不是只留下一个分数。

## 七、我的学情

「我的」标签页中的学情报告，帮助学生和家长掌握整体学习状况：

| 指标 | 说明 |
|------|------|
| 累计答题 | 累计完成的答题数量 |
| 正确率 | 总体作答正确率 |
| 连续天数 | 连续打卡学习的天数 |
| 学科掌握度 | 每个学科的掌握程度评估 |
| 学习路径 | 按薄弱程度把待攻克知识点排好顺序，每步配 AI 讲解卡与定向练习，沿路径逐个击破 |
| 学习日历 | 近 90 天打卡热力图，学习坚持一目了然 |
| 成绩趋势 | 历次考试与课堂快测的分数曲线，进步一眼可见 |
| 已掌握知识点 | 已经掌握的知识点数量 |
| 近 30 天趋势 | 最近 30 天作答量与正确率的变化趋势 |
| 班级答题榜 | 你在班级答题量榜单中的位置 |

长期没练的知识点，掌握度会缓慢回落并重新进入薄弱推荐——学情始终反映当前真实状态。讲解卡还提供自测模式：先只显示知识点名，点击再揭示内容，主动回忆记得更牢。

## 八、成长中心：周报、成就与 AI 定制练习

- **AI 学习周报**：每周一自动生成上周报告（本周亮点、待加强、下周建议），错过也可以手动补生成；
- **成就徽章**：12 枚徽章记录学习里程碑——首次作答、答题量、连续学习天数、掌握知识点、消灭错题、完成复习、AI 练习等，每枚徽章实时显示进度；
- **AI 对话式练习**：在 AI 家教页点「AI 出题练练」，AI 按你的薄弱知识点现场出一份定制小卷，生成完成即可开练；题目为你私有，不进公共题库。

## 九、AI 家教：随时在线的答疑老师

AI 家教是贯穿全平台的智能答疑入口，主要有四个特点：

- **个性化答疑**：答疑结合你的错题本，优先围绕你真实做错过的题目讲解，而不是泛泛而谈；
- **拍照识题讲解**：遇到不会的题，拍照即可识别题目并获得讲解；
- **引导模式**：开启后 AI 只提示思路、不给最终答案，先启发你自己想，实在想不出再逐步深入；
- **AI 出题练练**：让 AI 按你的薄弱点现场出一份定制练习卷，即出即练；
- **历史对话**：所有问答都有历史记录，随时回看之前问过的问题。

::: tip 引导模式的教育意义
直接看答案只会带来「我看会了」的错觉，下次遇到同类题还是不会。引导模式下，AI 像一位耐心的老师那样反问、提示、搭台阶，让孩子自己走完思考过程——这正是「AI 家教」与「搜题软件」的本质区别。建议家长为孩子开启引导模式。
:::

## 十、作业、收藏与笔记

- **作业**：今日任务中会聚合待交作业；作业模块分为「待完成」与「已提交」，并明确显示**截止时间**，避免遗漏；**截止自动提醒**：截止前 24 小时系统会自动提醒所有未交同学（站内信+微信），即使老师忘记催交也不会漏；
- **题目收藏**：好题、典型题可以收藏，方便考前集中回看；
- **笔记**：做题过程中可以随手记录笔记，把解题心得沉淀下来。

## 十一、微信提醒与家长可见

- **微信提醒**（小程序端）：在设置中绑定微信并完成订阅后，复习到期、作业催交、批改完成、周报生成会直接推送到你的微信；各事件是否推送可在「通知偏好」里自选；
- **家长绑定**：在「我的」菜单生成 10 分钟有效的 6 位邀请码发给家长；家长注册/登录学生端后，在「家长页」输入邀请码绑定，即可查看子女的学情总览、学习周报与作业完成情况，周报生成时自动推送。

## 十二、常见问题

**Q：主观题什么时候出分？**
A：主观题由 AI 异步批改，不是提交后立即出分。提交后稍等片刻，回到练习记录或作业列表查看即可，出分时会附带 AI 评语。

**Q：变式训练的题目和同学一样吗？**
A：不一样。AI 变式题按学生私有隔离生成，每位同学基于自己的错题得到不同的变式题，无法直接「抄作业」。

**Q：切屏一次会被判作弊吗？**
A：切屏次数会被记录并对教师可见，是否处理由教师判断。考试时请专注于作答页面，不要切出去查资料。

**Q：电脑上也能用吗？**
A：可以。学生端同时提供微信小程序与 H5 两种形态，H5 在手机或电脑浏览器中均可访问，数据实时同步。

**Q：复习任务太多完不成怎么办？**
A：优先完成今日任务里标为「到期复习」的题目；答对的题复习间隔会自动拉长，坚持一段时间后每天的复习量会稳定在合理水平。

**Q：拍题录错题识别错了怎么办？**
A：识别结果会先展示题干，可以直接删掉重拍；录进去的错题与普通错题走完全一样的复习计划。

**Q：家长怎么看孩子的学情？**
A：学生在「我的」菜单生成 6 位邀请码发给家长，家长登录学生端在「家长页」绑定后，即可查看学情总览、学习周报与作业完成情况，周报生成时自动推送。
