# 教师端与管理端功能指南

教师端面向学科教师与教务人员，通过 **Web 管理后台**使用，覆盖从建设题库、组卷发布、布置作业、批改到学情分析的教学全流程；管理端面向学校/机构管理员，负责组织人员、角色权限、审计日志与 AI 基建等平台级治理。

::: tip 账号说明
教师账号由学校/机构管理员在后台**统一创建**；学生无需教师逐个录入——他们在学生端自助注册后，通过**班级加入码**加入对应班级。
:::

## 一、基础数据准备

开始使用前，先完成三类基础数据：

| 模块 | 说明 |
|------|------|
| 学科管理 | 维护语文、数学、英语等学科体系 |
| 知识点管理 | 以**树形结构**维护各学科知识点，是选题、组卷、薄弱点统计的共同骨架 |
| 班级管理 | 通过**班级加入码**让学生自助入班，无需逐个录入学生信息 |

::: tip 知识点树建得越细，个性化越准
智能练习的薄弱点选题、AI 组卷的抽题范围、学情看板的薄弱知识点榜，全部依赖知识点树。建议按「学科 → 章节 → 知识点」完整梳理后再开始建题库。
:::

## 二、题库建设

题库是平台的核心资产，教师端提供从录入到质检的完整工具链：

| 能力 | 说明 |
|------|------|
| 六种题型 | 覆盖客观题与主观题共六种主流题型 |
| Excel 批量导入导出 | 按模板批量导入题目；也可导出题库，线下协作编辑后再导入 |
| AI 出题 | 选定知识点让 AI 生成题目，系统通过**语义向量查重**避免与既有题目重复 |
| OCR 拍照录题 | 纸质试卷、教辅拍照识别即可录题，快速完成存量题目数字化 |
| AI 配图 | AI 为题目自动配图，省去手工制图 |
| 相似题检索 | 按语义检索相似题目，避免重复收录同类题 |
| 草稿/发布两态 | 题目先存草稿，教师复核确认后再发布进入可用题池 |

::: tip 推荐的建库流程
纸质历史试卷 → OCR 拍照录题 → AI 补充生成新题（语义查重自动去重）→ 教师逐题复核草稿 → 发布。一名教师在较短时间内即可完成一个学科的基础题库搭建。
:::

## 三、组卷与发布控制

### 三种组卷方式

| 方式 | 做法 | 适合场景 |
|------|------|----------|
| 手工组卷 | 从题库逐题挑选，完全掌控试卷结构 | 正式测验、精选卷 |
| AI 组卷 | 设定知识点与难度要求，系统自动抽题并**自动均分**，一键成卷 | 日常练习、快速出卷 |
| 再练卷 | 基于班级**高频错题一键生成再练卷** | 针对全班共性错误组织再训练 |

### 发布控制

试卷发布时可以设置多种控制项，适配不同教学场景：

| 控制项 | 说明 | 典型用途 |
|--------|------|----------|
| 时间窗 | 限定可进入作答的时间段 | 全班统一组织考试 |
| 限次 | 限定作答次数 | 正式测验只允许作答一次 |
| 限时 | 限定单次作答时长 | 模拟真实考试节奏 |
| 排名开关 | 决定是否生成并展示排行榜 | 平时练习可关闭，减轻排名压力 |

::: warning 课后练习建议关闭排行榜
排行榜适合测验场景激发竞争，日常练习建议关闭，避免学生为冲榜刷题而忽视订正与复习。排行榜、限次、限时组合使用，才能兼顾激励与公平。
:::

## 四、作业与催交

作业 = **班级 + 试卷 + 截止时间**，布置与管理都很直接：

- 布置作业时选择班级、关联试卷、设定截止时间；
- **完成率实时统计**：提交进度实时可见，不需要逐个询问学生；
- **一键催交**：向未完成的学生一键发送催交提醒；
- **作业延期**：特殊情况可调整截止时间，学生端同步更新。

学生侧的作业会出现在他们的「今日任务」与作业列表中（详见[学生端功能指南](./student.md)），临近截止还会聚合在待办里提醒。

## 五、批改中心

批改中心是教师日常使用频率最高的模块，核心思路是「**AI 初判、教师终判**」：

| 能力 | 说明 |
|------|------|
| AI 批改结果 | 客观题已即时判分；主观题由 AI 完成初步批改并附评语 |
| 一键采纳 | 认可 AI 评分的题目**一键采纳、批量终判**，把教师从重复劳动中解放出来 |
| 人工改分 | 对不认可的评分人工改分，改分后相关统计**自动重算**，无需手工调整 |
| 切屏次数预警 | 查看每位考生的切屏次数，异常次数自动预警，辅助判断考试纪律 |

::: warning AI 评分是建议，不是结论
AI 批改负责提效，**最终成绩以教师终判为准**。推荐的批改节奏：先批量采纳明显合理的评分，再集中精力复核主观题与存疑答卷；对 AI 生成的题目，结合「疑似问题题预警」一并复核。
:::

## 六、学情看板

学情看板把班级的作答数据变成可直接用于教学的图表与报告：

| 看板能力 | 教学用途 |
|----------|----------|
| 正确率总览 | 快速判断班级整体掌握情况 |
| 高频错题榜 | 找出全班错得最多的题目，课堂上重点讲评 |
| 薄弱知识点榜 | 定位共性薄弱知识点，安排专项复习 |
| 近 30 天趋势双轴图 | 同时观察作答量与正确率的变化趋势 |
| 错因分布 | 了解错误构成：是粗心、概念不清还是审题问题 |
| 疑似问题题预警 | AI 生成题出现错误率异常时自动预警，提醒复核题目本身质量 |
| AI 班级报告 | AI 自动生成 Markdown 格式班级学情报告，可直接用于教研与家长沟通 |
| 错题打印卷 | 按班级或学生生成错题打印卷，纸质再练 |

::: tip 讲评课的推荐节奏
考后先看「高频错题榜 + 错因分布」准备讲评内容 → 讲评后用「再练卷」组织针对性重练 → 过几天再看「薄弱知识点榜」验证薄弱点是否消除，再决定是否安排第二轮讲评。
:::

## 七、一个教学周期的完整工作流

把上面的能力串起来，一个「单元」的教学周期通常是这样运转的：

| 阶段 | 教师动作 | 平台支持 |
|------|----------|----------|
| 课前建库 | 沿用往年试卷 + 补充新题 | OCR 拍照录题、AI 出题、语义查重、草稿复核 |
| 单元练习 | 布置日常练习作业 | 班级 + 试卷 + 截止时间，完成率实时统计，一键催交 |
| 单元测验 | 组织正式测验 | 时间窗 + 限次 + 限时，题目选项乱序，切屏预警 |
| 批改讲评 | 批改与课堂讲评 | AI 批改 + 一键采纳终判；高频错题榜、错因分布辅助备课 |
| 复习巩固 | 针对薄弱点补练 | 高频错题一键生成再练卷；系统按遗忘曲线自动安排学生复习 |
| 周期复盘 | 教研与家长沟通 | AI 班级报告一键生成，错题打印卷下发纸质再练 |

每个周期结束后，学生的错题与薄弱知识点都会沉淀下来，成为下一轮智能练习与复习计划的输入——教学数据越用越准。

## 八、系统管理概要

管理端（系统管理）面向学校/机构管理员，提供平台级治理能力：

| 模块 | 说明 |
|------|------|
| 数据看板 | 平台整体使用概览与 AI 洞察 |
| 组织人员 | 学校/机构的组织架构与人员管理 |
| 角色权限（RBAC） | 按角色分配后台功能与数据权限，教师、教务、管理员各司其职 |
| 字典/多语言/文件/任务 | 平台基础配置、文件与后台任务管理 |
| 审计日志 | 六类审计日志，关键操作全程可追溯 |
| AI 基建 | 模型服务商管理（密钥加密存储）、知识库 RAG、AI 对话、智能问数、用量统计与内容安全 |

::: tip 管理员最该关注的两件事
一是**AI 用量统计**：了解各模型服务商的调用与消耗情况，控制成本；二是**审计日志**：定期检查关键操作记录，保证平台使用合规可查。模型密钥在平台内加密存储，不暴露给普通用户。
:::

## 九、常见问题

**Q：学生没有账号怎么办？**
A：学生端支持自助注册，教师只需把**班级加入码**发给学生，学生注册后凭加入码入班。

**Q：AI 出的题可以直接用吗？**
A：AI 出题会经过语义查重与疑似问题题预警，但建议保持「草稿 → 教师复核 → 发布」的流程，确认题目内容无误后再进入可用题池。

**Q：一个班几十份答卷，批改来得及吗？**
A：主观题由 AI 先行批改附评语，教师对合理评分一键采纳即可批量终判，只需复核少数存疑答卷；客观题在学生提交时已即时判分，无需人工参与。

**Q：换学期/换班后历史数据还在吗？**
A：作答、错题与学情数据按学生持续积累；学生通过加入码进入新班级后，新班级的看板与榜单随之更新。
