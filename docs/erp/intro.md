# GoWind ERP 产品介绍

GoWind ERP 是一款面向中小团队的企业级开源 ERP，围绕「**采购 — 库存 — 财务**」业务闭环设计，
主打**免实施顾问、半天上手、核心业务数据全打通**。

产品以「单据驱动单据」为核心理念：采购单审批通过后自动生成应付单，收货确认自动回写库存，
库存低于安全水位自动给出补货建议——业务数据一次录入、全链路自动流转，
采购、仓储、财务在同一套数据上协作，不再互相搬表对账。

GoWind ERP 是 GoWind 生态的开源项目，采用 **MIT 协议**开源，欢迎试用、反馈与共建；
同源的 GoWind WMS（多货主仓储管理系统）即由本产品库存模块衍生而来。
如需私有化部署与技术支持服务，请通过文末的联系方式与我们沟通。

## 一、核心亮点

### 1. 开箱即用，免实施顾问

- **核心流程内置**：采购、库存、财务主线流程开箱即用，无需实施顾问驻场配置
- **注册即初始化**：多租户注册完成后自动完成租户初始化，省去系统搭建的一次性投入
- **半天上手**：界面与流程贴合实际业务操作，中小团队学习成本低

### 2. 单据驱动单据的业务闭环

- **审批生成应付**：采购单审批通过后自动生成应付单，财务无需二次录入
- **收货回写库存**：收货确认自动回写库存，账实同源
- **低库存自动补货**：库存低于安全水位自动生成补货建议，备货有据可依
- **数据全打通**：单据间自动联动，采购、仓储、财务共用一套业务数据

### 3. 库存事务安全

- **库存状态机**：库存变动统一经由状态机流转，状态可预期、可追溯
- **跨仓调拨事务原子**：跨仓调拨单以事务方式原子执行，不会出现「发出仓已扣、调入仓未加」的中间态
- **冲正幂等**：冲正操作幂等设计，重复提交不会产生重复冲正

### 4. 统一审批轨，禁自审自批

- **统一审批轨**：关键单据走统一审批流程，审批记录全程留痕可查
- **禁自审自批**：强制要求提交人与审批人分离，杜绝自审自批
- **审批中心**：待办集中处理，配合站内信提醒，审批不遗漏

### 5. 移动端：扫码、审批、经营看板

- **Flutter App**：原生移动客户端，随时随地处理业务
- **扫码作业**：移动端扫码完成现场业务操作，减少手工录入差错
- **移动审批**：待审批事项手机上随时处理
- **经营看板**：管理者在移动端掌握经营概况

### 6. 多租户，注册即用

- **多租户架构**：租户间数据隔离，支持多团队共用一套部署
- **注册即初始化**：注册完成即自动初始化租户基础数据，即注册即使用
- **细粒度权限**：组织、角色、按钮级权限逐层管控，配合全链路审计

## 四、适用场景

### 中小团队的进销存与应付管理

- 采购下单、审批、收货、应付、付款一条线走完
- 应付与库存由单据自动联动，无需人工搬表对账
- 低库存自动补货建议，减少缺料断货

### 多仓库运营

- 跨仓调拨单事务原子执行，账实一致
- 库存状态机保证每笔变动可追溯
- 冲正幂等，纠错不怕重复操作

### 需要审批合规的团队

- 统一审批轨 + 禁自审自批，满足基本内控要求
- 全链路审计留痕，事后可追溯
- 管理者通过移动审批与经营看板远程掌控业务

## 五、技术栈与部署

GoWind ERP 后端基于 **go-kratos** 微服务框架构建，ORM 采用 **Ent**，数据存储使用 **PostgreSQL**；
管理后台基于 **Vue3 + Ant Design Vue** 构建，模板底座为 **Vben Admin**；移动端为 **Flutter App**。

部署采用 docker-compose 一键拉起中间件（PostgreSQL、Redis、MinIO、etcd，均绑定 127.0.0.1），
应用侧提供 admin BFF（`:6600`）与 app BFF（`:6700`）两个服务入口。
详细部署步骤见仓库内 `docs/deployment.md` 部署文档。
