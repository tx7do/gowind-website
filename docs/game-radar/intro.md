# GoWind Game Radar（游戏立项雷达）

GoWind Game Radar 是面向中小游戏团队的「研发量化大脑」：用客观的社群大数据、直播流量、榜单与竞品评价数据，**算出**海外游戏市场的下一个研发方向、爆款创意与市场空白——解决「研发执行力极强、主观创意不足」的立项困境。

25 个数据源汇成小时级「游戏 K 线」，六类研发信号自动扫描推送；细分生存位扫描与同量级生存数学专门回答中小厂最关心的两个问题——「往哪站」与「活不活得下来」；立项沙盘把信号落成「做哪几个、各投多少、何时启动」。

> 与 GoWind Quant（量化研究）、GoWind Trade Radar（外贸选品雷达）同一产品范式：「采集 → 数据底座 → 信号 → 回测 → 决策 → 反馈闭环」，落到游戏立项场景。

## 核心亮点

- **25 源采集，24 个免凭证**：Steam（在线数/榜单/评测/即将发行）、App Store 双榜、Twitch、Reddit、YouTube、itch.io 与 Game Jam、Discord、Roblox、TapTap、B站、Google Trends 等，开箱即采
- **六类信号，覆盖立项全判断**：题材动能、跨平台套利、竞品痛点、趋势预测、竞品骤降、买量毒药
- **先回测，再使用**：动能/骤降/套利三策略参数网格回测，命中率与兑现倍数先行验证
- **中小厂专属镜头**：细分生存位扫描回答「往哪站」，同量级生存数学回答「活不活得下来」，沙盘单注模式回答「要不要 all-in」
- **玩家口碑深度挖掘**：差评聚类出痛点与微创新 Hook，爽点下钻提炼竞品的核心体验回路与爽点图谱——痛点告诉你玩家骂什么，爽点告诉你玩家为什么上头
- **越用越准**：信号标注 → 准确率统计 → 实体可信度排行，反馈闭环内建

## 功能全景

### 1. 情报采集

| 功能 | 说明 |
|---|---|
| 覆盖 25 源 | Steam（在线数/官方畅玩榜/新闻/评测/国区热销/群组/即将发行/定价与折扣）、Apple App Store 免费榜 + 畅销榜（cn/us 双区）、Twitch、Reddit、YouTube、itch.io 榜单 + Game Jam、Discord 社群规模、Roblox 在线数、Epic 限免、TapTap、B站游戏区、HackerNews、Google News、Wikipedia 浏览量、Google Trends 兴趣指数等 |
| 游戏库页面化管理 | 监控哪些游戏自己登记——每个实体挂跨平台足迹（Steam AppID/苹果 track id/TapTap/维基页面），保存即生效 |
| 采集源运维 | 每个源的健康状态、最近成功时间与新鲜度徽章，连续失效自动告警 |

### 2. 数据底座

| 功能 | 说明 |
|---|---|
| 小时级「游戏 K 线」 | 原始数据校验/归一/小时聚合，产出 13 类指标时序：在线数/榜位/提及量/好评率/社群规模/搜索兴趣/现价与折扣等 |
| 长期保留 | 聚合时序长期保存，回测与复盘始终有历史可依 |

### 3. 六类信号（自动扫描 + 多渠道推送）

| 信号 | 回答的问题 |
|---|---|
| 题材动能 MOMENTUM | 谁开始被讨论了 |
| 跨平台套利 ARBITRAGE | PC 火了，移动端还没人做 |
| 竞品痛点 PAIN_POINT | 玩家在骂什么 |
| 趋势预测 TREND | 6-12 个月后这个题材会怎样 |
| 竞品骤降 DOWNSWING | 谁在掉链子，我们的抢窗口在哪 |
| 买量毒药 UA_POISON | 谁在烧钱冲榜，虚火别跟 |

信号统一落盘去重，推送飞书 / 钉钉（可加签）/ Slack / Telegram / 邮件 / webhook，页面化渠道管理、按种类与级别路由。

### 4. 验证深潜

| 功能 | 说明 |
|---|---|
| 回测调参 | 动能/骤降/套利三策略 × 9 组参数网格热力图，命中率 + 兑现倍数 P50/P90——策略先验证再使用 |
| 竞品痛点报告 | 差评聚类（痛点指数/占比/典型原话/微创新 Hook） |
| 爽点下钻（AI） | 一键提炼竞品的核心体验回路、爽点图谱、玩家情绪与立项借鉴 |
| 吸量素材验证 | 立项前用伪宣传素材验证题材动能：AI 吸量 brief → 回填各渠道曝光/点击 → CTR 自动对照 |
| AI 分析按钮 | 信号解读/痛点分析/回测复盘/关注简报，页面内一键调用 |

### 5. 决策输出

| 功能 | 说明 |
|---|---|
| 机会评分卡 | 痛点 × 骤降 × 套利联合打分（0-100 进入窗口分），横向排期依据 |
| 立项沙盘 | 输入总预算与规划期，自动产出「做哪几个、各投多少、何时启动」——组合/单注双模式，买量毒药一票排除 |
| 细分生存位扫描 | 每个品类词根一个 0-100 生存位分：需求热度 × 供给缺口 × 头部可击穿度 × 小队胜出证据 |
| 同量级生存数学 | 预算 → 保本份数 → 保本评测数 × 同量级带对标分布 → CLEAR/TIGHT/BELOW 判定 |
| 决策周报 | 评分卡 TOP/买量竞争/品类大盘/痛点动态一报打尽，专设「中小厂立项镜头」，置顶 AI 编者按（发行总监人格）：本周【立刻上】谁、【别碰】谁 |
| 竞品发行日历 | 竞品上架/发行时间线，供给洪峰一目了然 |

### 6. AI 助手平台

| 功能 | 说明 |
|---|---|
| 雷达上下文对话 | 流式对话，可挂载当前页面数据一起问 |
| 智能问数 | 自然语言直查业务数据，表白名单/只读事务/超时/限量四重护栏 |
| AI 晨报 | 每日自动汇总昨日指标/信号/痛点，LLM 合成推送 |
| 知识库 RAG | 文档切片、向量检索，对话自动引用知识库作答 |
| 提供商管理 | OpenAI 兼容协议，DeepSeek/OpenAI/Qwen/GLM 均可，页面维护、凭证加密 |

### 7. 反馈闭环

| 功能 | 说明 |
|---|---|
| 信号标注 | 有用/误报一键标注，分种类准确率统计与误报归因 |
| 实体可信度排行 | 一个题材的历史信号准不准，排行一眼可见 |
| 数据导出 | 信号流水/指标时序 CSV、Excel 导出 |

## 适用场景

- **中小游戏厂立项评审**：生存位 × 生存数学 × 沙盘，把「拍脑袋立项」变成可辩论的数据决策
- **独立团队选题材**：萌芽词与生存位扫描找「大厂看不上、需求在涨」的缝隙
- **发行商选品评估**：用同量级生存数学评估合作团队项目的存活概率
- **买量投放团队**：买量毒药识别烧钱冲榜的虚火，别把推广费打进红海
