# 中小厂的立项数学

> 本页面面向制作人、发行与主策视角，解读 Game Radar 为中小团队专门设计的三个决策工具：细分生存位扫描、同量级生存数学与立项沙盘（组合/单注）。不涉及具体品类结论与业绩数据。

大厂盯大盘：头部品类、成熟赛道、长线运营。中小团队的问题完全不同——预算有限、团队规模有限、一次失败可能没有下一次。Game Radar 把这些问题拆成三道可计算的题：

1. **往哪站**——细分生存位扫描
2. **活不活得下来**——同量级生存数学
3. **要不要做、做几个、各投多少**——立项沙盘

## 一、细分生存位扫描：往哪站

每个品类词根出一个 0-100 的「生存位分」，由四个分量综合得出：

| 分量 | 回答的问题 |
|---|---|
| 需求热度 | 这个题材有没有人在讨论、在搜索 |
| 供给缺口 | 在做的团队多不多，供给是否已经饱和 |
| 头部可击穿度 | 头部声量份额（CR1）越分散，越有切入缝隙 |
| 小队胜出证据 | 同品类有没有小评测量仍存活的游戏——「小队赢过」的直接证据 |

并在总分上做三类折减：供给洪峰（待发行扎堆）、大厂虹吸（头部新作吸走声量）、大盘降温。

**用法**：决策周报直接给出生存位 TOP3——不是抽象的「题材热度榜」，而是「中小队站得住的位置榜」。配套的同量级生存数学计算器可以针对单个候选题材做保本演算。

## 二、同量级生存数学：活不活得下来

输入三个数：预算、定价、对标品类。系统算出一条保本链：

**预算 → 保本份数 → 保本评测数**（按拥有量/评测比换算）→ 与同量级带（参照体量的 1/3 至 3 倍）同类对标的评测分布对照 → **CLEAR / TIGHT / BELOW** 三档判定：

- **CLEAR**：同量级里已有团队用相近评测量活下来了，你算得出余量
- **TIGHT**：踩着保本线，几乎没有试错空间
- **BELOW**：需要超出同量级常识的表现才能回本，慎重

**用法**：立项会上不辩论「我觉得能成」，而是辩论「这个 BELOW 判定里，哪一项假设我们比对标团队强」——把主观分歧逼到具体假设上。

## 三、立项沙盘：做哪几个、各投多少、何时启动

### 组合模式

输入总预算与规划期，产出组合建议：

- 评分卡 × 回测 × 预测三因子打分排序
- 买量毒药一票排除
- 同品类上限 2 个，供给洪峰错峰 60 天
- 预算 80-20 分配（单项封顶 40%）

### 单注模式（中小厂 all-in 视角）

只出一个建议并给 **GO / WAIT / NO-GO** 判定：入选项拿满 80% 预算池不拆注，准备金只用于救场——纪律先于乐观。适合团队规模只够同时做一个项目的中小厂。

## 四、吸量素材验证：立项前再测一次

题材动能是真火还是虚火，可以用最低成本先测一次：

1. 登记素材概念（挂实体/渠道/图片）
2. AI 吸量 brief：卖点钩子、伪宣传图方向 ×3、渠道受众、CTR 基线判定规则
3. 回填各渠道曝光/点击
4. CTR 自动汇总着色，与信号的虚拟回测互证

概念图没人点，题材再热也冷——数据先于投入。

## 五、决策周报里的立项镜头

定时生成的决策周报专设「中小厂立项镜头」：

- **生存位 TOP3**：本周最值得看的细分位置
- **生命周期候选**：候选题材处于萌芽/上升/成熟/衰退哪一段，回答「做完时需求还在吗」
- **虹吸时点警报**：头部新作什么时候吸走声量，避开正面窗口
- **单注纪律**：all-in 项目是否仍满足单注前提

置顶 AI 编者按（发行总监人格）：本周【立刻上】谁、【别碰】谁，一句话排期裁决——把周报从「信息汇总」变成「排期裁决」。
