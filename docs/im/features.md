## 一、消息沟通

| 功能 | 您可以做什么 |
|---|---|
| 单聊 / 万人群 | 一对一私聊，或创建最多万人的大群，全员通知一呼即应 |
| 频道 | 面向全员或部门的广播式发布，订阅后定向触达 |
| 聊天室 | 开放式实时聊天场景，适合活动互动、临时协作 |
| 密聊 | 消息**定时自动撤回**、对方**截图即时告警**、画面叠加**暗水印**，涉密沟通更安心 |
| 话题线程 | 把群内一段讨论聚合成话题，后续回复集中归档，不打扰他人 |
| 定时消息 | 撰写后预约发送时间，跨时区协作不再熬夜 |
| 消息管理 | 撤回、引用、转发、收藏，常用操作一应俱全 |
| 全文搜索 | 跨会话搜索消息与文件，历史结论快速找回 |
| 位置共享 | 发起实时位置共享，外勤集合、客户拜访更高效 |
| 表情包商店 | 在商店中挑选收藏表情包，团队沟通更有温度 |
| 多端漫游 | 手机、电脑等多端登录，聊天记录自动同步漫游 |

![会话窗口](/assets/images/im/03_chat.png)

*会话窗口：话题、引用、表情与密聊能力入口都在聊天界面中*

::: tip 典型场景
- **全员通知**：用频道广播 + 万人群，制度和公告一次触达全员；
- **涉密沟通**：涉及薪酬、并购等敏感话题改用密聊，消息定时撤回、截图告警、暗水印三重保护；
- **找历史结论**：不用翻聊天记录，全文搜索直接定位当时的文件与决定。
:::

## 二、音视频会议

| 功能 | 您可以做什么 |
|---|---|
| 1v1 通话 | 在聊天窗口一键发起点对点音视频通话 |
| 多人会议 | 创建多人会议，支持会前邀约与会中邀请 |
| 主持人管控 | 主持人可静音、移出成员、锁定会议，维持会议秩序 |
| 屏幕共享 | 共享整块屏幕演示文档、评审方案 |
| 云录制与回放 | 会议云端录制为 MP4，缺席同事可随时回看 |
| 群直播 | 群内开播，成员进入直播间观看并发表弹幕互动 |
| 语音转文字 | 语音消息与通话内容自动转写为文字，方便存档与检索 |

::: tip 典型场景
- **例会与评审**：多人会议 + 屏幕共享 + 云录制，缺席同事看回放即可跟上进度；
- **全员宣讲**：群直播 + 弹幕互动，年会、培训线上化；
- **跨语言会议**：会话级自动翻译配合语音转文字，中外团队顺畅协作。
:::

## 常见问题

**Q：密聊与普通聊天有什么区别？**

密聊中的消息会**到时自动撤回**，对方**截图会触发告警**，且画面带有**暗水印**可溯源，适合敏感事项沟通。

**Q：AI 功能会产生额外费用吗？**

平台提供**租户级 token 用量限额**，管理员可为不同部门设置配额，AI 用量透明可控。

**Q：原来用的 Trello 看板怎么迁移？**

项目管理内置 **Trello 导入**能力，存量看板一键迁移，任务与状态完整保留。

**Q：外部客户如何联系我们？**

访客通过**网页**即可与企业客服会话，无需安装客户端；有采购意向的咨询可**转入 CRM** 持续跟进。

::: tip 版本与功能可用性
部分功能（如研发协同、访客客服、CRM / ERP）依赖所选授权版本，请参阅 [产品介绍 · 版本与授权](/im/intro.md#四、版本与授权)。
