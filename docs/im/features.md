## 一、消息沟通

| 功能 | 您可以做什么 |
|---|---|
| 单聊 / 万人群 | 一对一私聊，或创建最多万人的大群；支持普通群、部门群、**事件群**（随事件终结自动归档）等群形态，全员通知一呼即应 |
| 频道 | 面向全员或部门的广播式发布，订阅后定向触达 |
| 聊天室 | 开放式实时聊天场景，适合活动互动、临时协作 |
| 密聊 | 消息**定时自动撤回**、**已读焚毁**（读后自动删除）、对方**截图即时告警**、画面叠加**暗水印**，涉密沟通更安心 |
| 话题线程 | 把群内一段讨论聚合成话题，后续回复集中归档，不打扰他人 |
| 定时消息 | 撰写后预约发送时间，跨时区协作不再熬夜 |
| 群协作工具 | 群投票（支持**匿名投票**、截止时间与数据收回）、**群接龙**、群相册、任务打卡，群内事务一站办理 |
| 消息管理 | 撤回、引用、转发、收藏、**窗口抖动**提醒，常用操作一应俱全 |
| 会话分组页签 | 会话列表按全部 / @我 / 未读 / 单聊 / 群聊 / **应用**快速筛选，消息再多也不乱 |
| 文件签收回执 | 重要文件可要求**确认回执**，谁已签收、谁未读一目了然，未读还可一键催收 |
| 大文件与文件夹 | 聊天文件**断点续传**（大文件分片上传、中断续传），支持直接**发送文件夹** |
| 群发消息 | 群发助手一次选人、逐人送达，通知触达不漏一人 |
| 全文搜索 | 跨会话搜索消息与文件；会话内可按**文档 / 图片 / 视频**分类快查，历史结论快速找回 |
| 位置共享 | 发起实时位置共享，外勤集合、客户拜访更高效 |
| 手机通讯录与系统分享 | 组织部门页一键**同步到手机通讯录**；微信、QQ 里的文件可经**系统分享**直接发进会话 |
| 表情包商店 | 在商店中挑选收藏表情包，团队沟通更有温度 |
| 多端漫游 | 手机、电脑等多端登录，聊天记录自动同步漫游 |

![会话窗口](/assets/images/im/03_chat.png)

*会话窗口：话题、引用、表情与密聊能力入口都在聊天界面中*

::: tip 典型场景
- **全员通知**：用频道广播 + 万人群，制度和公告一次触达全员；
- **涉密沟通**：涉及薪酬、并购等敏感话题改用密聊，消息定时撤回、已读焚毁、截图告警、暗水印多重保护；
- **重要文件下发**：制度文件要求签收回执，未读一键催收；大附件断点续传，网络中断也不用重传；
- **找历史结论**：不用翻聊天记录，全文搜索直接定位当时的文件与决定。
:::

## 二、音视频会议

| 功能 | 您可以做什么 |
|---|---|
| 1v1 通话 | 在聊天窗口一键发起点对点音视频通话 |
| 多人会议 | 创建多人会议即提醒参会人，支持会前邀约与会中邀请 |
| 主持人管控 | 主持人可静音、移出成员、锁定会议，维持会议秩序 |
| 屏幕共享 | 共享整块屏幕演示文档、评审方案 |
| 会议内文件共享 | 会议中直接共享云盘文件，参会人点击即看 |
| 会中互动 | 举手发言、会中投票、实时字幕等快捷面板，会议节奏尽在掌握 |
| 远程协助 | 发起一对一**屏幕协助**：对方只看你的屏幕（只看不控），远程指导更安全 |
| 云录制与回放 | 会议云端录制为 MP4，缺席同事可随时回看 |

## 常见问题

**Q：密聊与普通聊天有什么区别？**

密聊中的消息会**到时自动撤回**，还可开启**已读焚毁**（对方读后自动删除），对方**截图会触发告警**，且画面带有**暗水印**可溯源，适合敏感事项沟通。

**Q：大文件传输稳定吗？**

聊天文件支持**分片断点续传**，网络中断后重发同一文件自动从断点续传；还支持直接**发送文件夹**，批量资料一次发齐。

**Q：AI 功能会产生额外费用吗？**

平台提供**租户级 token 用量限额**，管理员可为不同部门设置配额，AI 用量透明可控。

**Q：原来用的 Trello 看板怎么迁移？**

项目管理内置 **Trello 导入**能力，存量看板一键迁移，任务与状态完整保留。

**Q：外部客户如何联系我们？**

访客通过**网页**即可与企业客服会话，无需安装客户端；有采购意向的咨询可**转入 CRM** 持续跟进。

::: tip 版本与功能可用性
部分功能（如研发协同、访客客服、CRM / ERP）依赖所选授权版本，请参阅 [产品介绍 · 版本与授权](/im/intro.md#四、版本与授权)。
:::
