# GoWind IM（风信）产品介绍

GoWind IM（风信）是一款**企业级即时通讯与协同管理平台**：以即时通讯为底座，将音视频会议、OA 办公、项目管理、协作文档、客户经营（CRM / ERP）、研发协同与 AI 助手整合到同一个工作台。企业不再需要在「聊天工具 + 会议软件 + OA + 项目工具 + CRM」之间来回切换，一套平台即可支撑日常沟通、内部协作与业务经营。

GoWind IM 为**闭源商用软件，采用私有化交付**：系统部署在企业自有服务器上，聊天记录、文档与客户数据全部留在企业内网，满足数据主权与合规要求。

## 一、核心亮点

### 1. IM 核心沟通

- **单聊与万人群**：一对一会话与最多万人大群，消息实时到达、多端同步；
- **频道与聊天室**：频道支持广播式全员触达，聊天室适合直播互动、临时协作等轻量场景；
- **密聊模式**：消息可设定到时自动撤回，对方截图即时告警，并叠加暗水印便于溯源，满足涉密沟通需要；
- **话题线程**：群内讨论可聚合为话题，重要结论不再被刷屏淹没；
- **定时消息**：消息可预约在未来指定时间发送；
- **全文搜索**：跨会话检索历史消息，找文件、找结论一搜即得；
- **实时位置共享**：外勤、外出场景可发起位置实时共享；
- **表情包商店**：内置表情包商店，团队氛围表达更丰富；
- **多端漫游**：聊天记录在手机、电脑等多端自动漫游同步。

### 2. 音视频会议

- **1v1 通话**：从聊天窗口一键发起点对点音视频通话；
- **多人会议**：支持主持人管控——静音成员、移出成员、锁定会议等会控操作；
- **屏幕共享**：演示文档、评审方案时共享屏幕；
- **云录制与会议回放**：会议云端录制为 MP4，缺席同事可随时回看；
- **群直播与弹幕**：群内开播、弹幕互动，适合宣讲、培训场景；
- **语音转文字**：语音消息与通话自动转写文字，纪要整理更省力。

### 3. AI 能力

- **AI 客服自动回复**：常见问题由 AI 先行应答，减轻人工客服压力；
- **会话 AI 摘要**：长聊天记录一键生成摘要，快速掌握结论与待办；
- **AI 工单**：对话中发现的问题可转为 AI 辅助处理的工单流转；
- **会话级自动翻译**：跨语言沟通实时翻译，中外团队协作无障碍；
- **企业知识库 RAG**：接入企业自有文档，AI 基于企业知识回答问题；
- **AI 站会纪要**：自动生成每日站会纪要；
- **token 租户限额**：管理员可为不同租户设置 AI 用量配额，成本可控。

### 4. 办公协同

- **OA 审批**：内置六大类常用审批，配套可视化流程设计器，业务人员即可自行调整流程；
- **考勤打卡**：GPS + WiFi 双重定位校验，支持排班管理；
- **工作汇报**：日报、周报在线提交与汇总；
- **企业公告**：重要通知全员精准触达；
- **OKR 目标管理**：目标对齐树可视化、周期评分，并自动生成 AI 周期总结；
- **HR 入职建号**：新员工入职一步完成账号开通；
- **Base 多维表格**：业务人员可自建数据台账，灵活整理业务数据；
- **日历与会议室预订**：日程、会议与会议室资源一体化安排。

### 5. 协作文档与知识库

- **多人实时协同编辑**：文档多人同时编辑，改动实时可见；
- **知识空间**：按团队、项目组织知识，持续沉淀企业资产；
- **画板帧回放**：白板画板支持逐帧回放创作过程，评审与复盘一目了然。

### 6. 项目管理

- **看板泳道**：任务看板按泳道管理，进度状态一目了然；
- **自动化规则**：状态流转、指派提醒等重复操作可配置为自动化规则；
- **燃尽图**：迭代进度实时可视化；
- **Trello 导入**：存量 Trello 看板可一键迁移；
- **贡献榜游戏化**：成员贡献排行榜，激励团队积极参与。

### 7. 客户经营

- **CRM 客户关系管理**：六阶段商机漏斗逐级推进，「客户 360」视图聚合沟通记录、跟进与订单信息；
- **ERP 企业资源计划**：覆盖采购、库存、财务、销售，业务数据与沟通同平台流转。

### 8. 研发协同

- **代码评审**：对接 GitLab / Gitea / GitHub / SVN 代码仓库，评审动态直达群聊；
- **CI/CD 构建卡**：流水线构建状态以卡片形式推送到群聊，发布进展全员可见；
- **on-call 值班**：值班排班与告警响应闭环；
- **DORA 报表**：研发效能关键指标报表，持续改进有据可依。

### 9. 内容社区

- **朋友圈**：企业内部动态分享与互动；
- **短视频**：竖滑式短视频流，培训与宣传内容沉浸浏览；
- **群直播**：直播能力覆盖培训、宣讲、文化活动等场景。

### 10. 访客客服

- **网页访客会话**：外部访客无需安装 App，通过网页即可与企业客服沟通；
- **工单转 CRM**：访客咨询沉淀为工单，可转入 CRM 跟进为商机。

### 11. 安全管控

- **会话水印**：客户端叠加水印，泄露截图可溯源；
- **登录风控**：异地登录实时提醒；
- **设备管理**：登录设备统一管理，支持远程下线；
- **敏感词过滤**：消息内容敏感词检测与拦截；
- **审计日志**：敏感操作全量留痕可查；
- **聊天记录留存归档导出**：满足行业留存合规要求，支持归档与导出。

### 12. 数据报表

- **BI 固定报表**：常用经营与协作指标开箱即用；
- **自定义仪表盘**：按部门与业务视角自由搭建数据仪表盘。

## 四、版本与授权

GoWind IM 按**账号数**授权。license 采用 **Ed25519 离线签名**，与部署机器的**机器指纹绑定**，并按账号数门控开通容量，无需联网即可完成授权校验。

| 版本 | 包含内容 | 适合 |
|---|---|---|
| **社区版（Community）** | 18 项核心服务：IM 沟通、音视频、办公协同、安全管控等基础能力 | 小团队起步与内部试用 |
| **专业版（Professional）** | 社区版全部能力 + 11 项：研发协同、群机器人、访客客服等 | 需要研发协作与对外客服的团队 |
| **旗舰版（Enterprise）** | 专业版全部能力 + 8 项：CRM、ERP 等业务经营能力 | 需要沟通与业务一体化的大型组织 |

::: tip 授权续期无感
license 到期后提供 **7 天宽限期**，期间业务不中断；续期只需**覆盖 license 文件**，**无需重启服务**。
:::

## 五、交付与部署

- **私有化一键交付**：提供 Docker Compose 与二进制两种交付形态，配套安装脚本、升级手册与 SHA256 完整性校验，开箱即用；
- **信创适配**：支持 arm64 架构，兼容鲲鹏、麒麟等信创环境；
- **数据本地化**：全部数据存储在企业自有服务器，不依赖外部云服务。
