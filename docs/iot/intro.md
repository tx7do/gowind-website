# GoWind IoT（风行物联网）产品介绍

GoWind IoT（风行物联网）是基于 Go **微服务架构**的物联网设备管理与分析平台：从设备接入、视频监控、遥测存储，到规则引擎、告警处置、OTA 运维与数据大屏，覆盖物联网项目交付的完整链路。平台采用**闭源商用、多租户**模式，私有化交付，数据全部留在客户自有环境。

无论您是设备制造商、系统集成商还是行业客户，都可以用一套平台完成「设备统一接入、数据统一治理、业务统一编排」，把项目交付周期从「月」压缩到「周」。

## 一、核心亮点

### 1. 设备接入

::: tip
「零凭证上电」意味着现场施工无需提前准备每台设备的密钥：设备通电、联网即自动注册激活，千台级交付也不再逐台烧录。
:::

- **MQTT 接入 + 产品级动态注册**：设备**零凭证上电**即可自动注册激活，无需逐台烧录密钥，批量部署省时省力；
- **下行命令 + 回执状态机**：指令下发后全程跟踪「已下发 → 已送达 → 已执行」状态，执行结果不再靠猜；
- **消息级追踪**：每一条设备消息都可查询完整处理轨迹，现场排障有据可查；
- **工业协议**：支持 OPC-UA、Modbus TCP，直接对接 PLC 与工业网关。

### 2. 视频监控

::: tip
视频能力与告警联动：告警触发时自动抓图并留存事件短片段，监控与取证在一个平台内闭环。
:::

- **多协议摄像头接入**：支持 RTSP / GB28181 / ONVIF 摄像头统一接入与管理；
- **实时直播**：RTSP 优先、**亚秒级延迟**，同时提供 HLS / WebRTC 播放方式，适配网页与移动端观看；
- **录像归档与回放**：录像以 MP4 归档，随时回看历史画面；
- **视频墙**：2x2 分屏视频墙同时监看多路画面；
- **告警自动取证**：告警触发时自动抓图，并留存 **10 秒事件短片段**，现场情况一目了然；
- **播放令牌防盗链**：视频播放使用令牌机制，防止链接被盗用。

### 3. 遥测与时序数据

- **双存储**：设备最新值与历史数据分开存储，实时状态毫秒级可查，历史趋势长期可溯；
- **实时推送**：数据变化通过 SSE 实时推送到界面，**零轮询**，页面所见即设备当前所报；
- **趋势图表**：遥测数据趋势图表开箱即用，温湿度、电压电流等曲线随点随看。

### 4. 规则引擎

- **可视化规则链设计器**：拖拽式编排数据处理流程，支持多路分支、脚本节点，业务人员即可上手；
- **调试台**：规则上线前在调试台中模拟验证，改规则不再「盲改」；
- **丰富处理能力**：内置地理围栏判断、时间窗聚合、子链复用等常用处理单元；
- **执行历史与消息重放**：每条消息的规则执行历史可查，历史消息可重放验证，问题定位不再靠猜。

### 5. 告警

::: tip
告警不是「弹完就没了」：每条告警都有确认与清除的完整流转记录，事后可复盘谁在何时处置了哪条告警。
:::

- **状态机管理**：告警按「触发 → 确认 → 清除」状态机流转，处置责任清晰；
- **上下文面板**：告警详情直接附带**现场抓图与短录像**，不用来回切换系统确认现场；
- **值班视图**：值守界面弹窗提醒，关键告警不再漏接。

### 6. 地理围栏

::: tip
围栏区域在地图上圈画即生效，进出围栏自动告警，无需任何编码。
:::

- **可视化编辑器**：基于 GeoJSON 在地图上直接圈画围栏区域；
- **进出告警**：车辆、人员、设备进出围栏自动触发告警，适用于车队监管、资产看护等场景。

### 7. OTA 与设备运维

- **升级包管理**：固件/软件升级包统一管理，创建批量升级任务分批推送；
- **设备分组**：按地域、业务等维度分组，批量运维有的放矢；
- **设备影子 + 漂移记录**：为每台设备维护期望状态，实际状态与期望状态的差异（漂移）自动留痕；
- **设备模拟器**：没有硬件也能模拟设备上下线与上报，业务流程提前验证。

### 8. 数据大屏

::: tip
大屏由业务人员拖拽配置完成，不需要前端开发参与；改版只需在设计器中调整，当天即可重新投屏。
:::

- **配置化设计器**：内置 **51 种组件**，拖拽配置即可搭建监控大屏，无需开发；
- **模板库与主题**：常用大屏模板与主题开箱即用，快速起步；
- **分享与投屏**：大屏链接分享、浏览器直接投屏，支持**离线导出**归档展示。

### 9. AI 与报表

- **AI 周报自动化**：设备运行情况周报自动生成，运营汇报不再手工整理；
- **报表中心**：常用运营报表集中管理；
- **数据洞察**：对设备数据做聚合分析，发现运行规律与异常。

### 10. 通知

- **多渠道触达**：支持邮件、短信、Telegram、钉钉、企业微信、飞书等通知渠道；
- **统一收件箱**：站内信与桌面通知汇聚到收件箱，告警与通知一处查阅。

### 11. 平台能力

- **多租户**：集团多子公司、集成商多项目可隔离运营，数据互不可见；
- **MFA 多因素认证**：账号登录支持多因素校验，安全合规；
- **六类审计日志**：关键操作分类留痕，满足内控审查；
- **多语言界面**：界面支持中文、英文、日文三语切换。

## 二、适用场景

| 场景 | 平台能力的用法 |
|---|---|
| **环境监测** | 传感器遥测实时曲线、超限告警、历史趋势回溯，配合数据大屏对外展示 |
| **园区 / 厂区安防** | GB28181 / ONVIF 摄像头统一接入，视频墙值守，告警自动抓图取证 |
| **智慧风电 / 光伏** | 设备遥测汇聚、规则引擎自动判定、数据大屏投屏指挥中心 |
| **车队 / 资产监管** | 地理围栏进出告警，设备影子掌握每台设备的实际状态 |
| **设备批量交付运维** | 零凭证动态注册上电即用，OTA 批量升级，模拟器提前验证流程 |

这些场景均基于平台标准能力配置完成，无需定制开发。

## 三、客户端形态

| 形态 | 说明 |
|---|---|
| **Web 管理控制台** | 浏览器即可完成设备管理、规则配置、告警处置与大屏搭建 |
| **Qt6 桌面上位机** | 深色控制台风格，适配监控值守场景；支持大屏 Kiosk 轮播模式常驻展示 |
| **Flutter 移动 / 桌面客户端** | 一套代码编译 iOS / Android / Web / macOS / Windows / Linux 六端，深色控制台风格与 Qt6 上位机同源；SSE 实时推送，告警与遥测随时随地掌上可见 |
| **Web 大屏投屏** | 数据大屏通过浏览器直接投屏到指挥中心 / 展厅大屏 |

## 五、部署与交付

- **私有化交付**：平台整体交付到客户自有服务器或私有云，数据不出客户环境；
- **Docker Compose 一键起基础设施**：数据库、消息等基础设施一键拉起，降低部署门槛；
- **边缘安装脚本**：现场边缘侧部署提供安装脚本，实施人员按文档即可完成安装。
