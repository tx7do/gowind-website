# 风行记账

风行记账是一款基于 Go 微服务架构的个人 / 家庭记账平台，由 **Admin 管理后台**与 **Flutter 移动应用**组成，
覆盖收支记录、多账户、多币种、报表、预算与定期提醒，让每一笔钱记得轻松、看得清楚。
无论是个人日常记账，还是一家人共享账本，都能以轻量的方式把收支管起来。

风行记账是 GoWind 生态的开源项目，采用 **MIT 协议**开源：源码开放，欢迎试用、反馈与共建，
也欢迎通过文末的联系方式与我们交流。

## 一、核心亮点

### 1. 四种流水类型

- **支出 / 收入 / 转账 / 余额调整**：四种流水类型覆盖日常记账的全部场景；
- **单式记账上手即用**：采用单式记账法，每笔记录一行完成，没有借贷分录的学习成本。

### 2. 四类账户

- **活期 / 信用 / 资产 / 贷款**：四类账户覆盖现金银行卡、信用卡、投资资产与房贷车贷；
- **转账联动**：账户之间转账成对记录，余额自动更新，账实核对方便。

### 3. 分类与标签体系

- **4 层分类树**：收支分类支持四层层级，精细化归集每一笔支出；
- **标签体系**：一笔流水可挂多个标签，在分类之外叠加多维度归类。

### 4. 多币种记账

- **多币种收支**：外币收入、支出按币种记录，换算清晰；
- **汇率缓存与实时刷新**：汇率缓存加速查询，同时支持实时刷新，折算金额贴近真实。

### 5. 维度报表

- **多维度统计**：按分类、标签、收款人等维度出具收支报表；
- **ECharts 可视化**：报表以 ECharts 图表呈现，收支结构一目了然。

### 6. 预算管理

- **月 / 季 / 年 / 周预算**：按周期为分类或整体设定预算；
- **超额预警**：支出接近或超出预算即时预警，帮助管住手。

### 7. 家庭共享

- **组成员邀请工作流**：通过邀请流程把家庭成员加入同一账本，共同记账；
- **角色权限**：所有者 / 操作员 / 访客三级角色，各自按权限查看与操作。

### 8. 定期提醒

- **每天 / 每月 / 每年**：按周期设定记账提醒，房租、订阅、缴费、纪念日不再漏记。

## 四、适用场景

### 个人日常记账

想记就记，随手一笔：

- 单式记账上手即用，支出、收入一行完成；
- 移动端随时记录，后台统一汇总管理；
- 维度报表与 ECharts 图表，钱花在哪儿一目了然。

### 家庭共享账本

一家人记一本账：

- 通过邀请工作流把家庭成员加入同一账本；
- 所有者 / 操作员 / 访客角色分级，长辈孩子各按权限使用；
- 家庭收支、房贷车贷、共同储蓄集中呈现。

### 多币种与预算控制

有外币收支或想控制开支的家庭：

- 外币收支按币种记录，汇率缓存与实时刷新保证折算准确；
- 月 / 季 / 年 / 周预算配合超额预警，开支始终在计划内；
- 定期提醒覆盖房租、订阅、缴费等周期性支出，不再漏记。

## 五、技术栈与部署

后端基于 go-kratos 微服务框架构建，数据访问层采用 Ent ORM，业务数据由 PostgreSQL 存储；
Admin 管理后台基于 Vue3 构建，移动端使用 Flutter 开发。
本地部署通过 docker-compose 一键拉起中间件，业务服务按端拆分为 Admin BFF 与 App BFF 两组入口。

| 组件 | 说明 |
| --- | --- |
| 后端 | go-kratos + Ent + PostgreSQL，微服务架构 |
| Admin 后台 | Vue3 |
| 移动端 | Flutter |
| 中间件 | docker-compose 一键启动 |
| 服务端口 | Admin BFF `:6600`；App BFF `:6700` |
