# GoWind MES（风行 MES 制造执行系统）

GoWind MES 是一款面向**中小型离散制造企业**的轻量化制造执行系统（MES），覆盖「**销售订单 → 工单排产 → 车间执行 → 批次追溯 → 质量管理 → 设备管理**」的完整生产链路。车间执行全量结构化留痕，与 GoWind ERP、GoWind IoT 无缝集成：销售订单从 ERP 同步、设备遥测从 IoT 接入、报工工时与计件实时回传财务。

三句话讲清楚 GoWind MES：

- **免实施顾问** — 复用 GoWind 家族统一底座：多租户、组织人员、角色权限、审批流、站内消息、审计日志开箱即用，半天上手
- **批次即灵魂** — 投料/产出全链路绑定批次谱系，序列号单件追溯直达"这台机器是哪批料、哪台机、谁做的"
- **AI 就绪** — 报工、检验、遥测全量结构化留痕，预测性维护已落地（趋势外推 + ML 模型推理），智能排程、SPC 智能诊断持续深化

::: tip 版本说明
MES 六大业务域（计划排程、生产执行、质量、设备、主数据、平台支撑）功能已完整落地并通过端到端冒烟验收，目前处于**快速迭代阶段**，功能持续完善中。
:::

## 车间里的一天：GoWind MES 如何工作

**早上 8 点，计划员**打开车间看板：今日应产、在产工单、SPC 活跃告警、待处理维修工单一屏尽览；发现一张交期吃紧的工单，用**插单模拟**试算插入后的排程影响——不落库、不影响现排产，确认可行再正式下达。

**9 点，仓库备料**：工单投产前先跑**齐套检查**——按 BOM 比对可用批次库存，缺料一目了然；线上补料时**上料防错**守卫核对批次与 BOM，扫错料立即拦截，杜绝混料事故。

**9 点半，工人上工**：工位上打开**工位终端**，扫工单码即进入自己的工序——开工、暂停、恢复、完工四个大按钮，扫码即操作；工位旁的**电子 SOP** 展示作业步骤，遇到异常一键**安灯呼叫**，班组长手机立刻收到通知。

**下午 2 点，质检员巡检**：按**检验项目模板**执行首检/巡检，发现不良当场登记；不良品走 **MRB 评审**，处置结论（返工/让步/报废）自动回写批次状态；需要深入分析时一键**立项 CAPA 纠正预防**，按 8D 步骤走完根因分析与纠正措施。

**下午 4 点，客诉来了**：客户反馈某台音箱有杂音。输入产品上的**序列号**，正向追溯到整机批次，反向追到注塑外壳批次、喇叭单元批次——**哪批料、哪台机、谁当班、过了哪些检验**，30 秒内给出完整答案；确认批次后自动生成**召回清单**，影响范围一目了然。

**晚上 6 点，厂长看大屏**：车间大屏切换到质量主题看**一次合格率与直通率**，切到 OEE 主题看每台设备的可用率/性能/质量三率，再切到能耗主题看今天哪个机台最耗电、单耗有没有超标；月底导出**计划 vs 实际达成率**报表，准时交付率有了连续追踪。

这是 GoWind MES 为中小工厂设计的日常——**不用改变现有流程，把每一步自然搬进系统**。

## 核心亮点

- **车间大屏六主题**：综合 / 产量 / OEE / 质量（一次合格率 FPY、直通率 RTY、不良帕累托）/ 安灯（呼叫来源与响应时效）/ 能耗（合计与单耗趋势），一屏一视角，可投大屏常开
- **工位终端 Web 版**：扫码上工，开工/暂停/恢复/完工四个大按钮，工位 eSOP 同屏展示，异常呼叫直达班组长——普通电脑即可部署，工人零培训上手
- **一键自动排产**：交期优先、换型最小化、负载均衡多目标加权，支持设备级排程、**班次日历切割**（跨午夜夜班自动切班）、**冻结期避让**、**插单模拟**（干跑不落库）、**返工工单**（MRB 拒收一键建单）
- **扫码报工，工资实时算**：自动计算工时与计件工资，支持阶梯计件规则，**开工即校验上岗资质**（技能矩阵），完工校验首检/完工检放行
- **批次谱系 + 序列号双追溯**：批次级追料、序列号级追件，扫码直达谱系图谱，**召回清单**自动圈定影响范围
- **齐套检查与上料防错**：按 BOM 比对可用批次，防混料守卫全程护航
- **全链路质量闭环**：来料检/首检/巡检/完工检/OQC 出货检、不良登记、MRB 处置回写批次、CAPA-8D 纠正预防、SPC 控制图（计数型+计量型、Nelson 判异、Cpk/Ppk）、AQL 抽样建议、召回清单、质量报告打印
- **预测性维护**：设备健康度评分与异常概率实时呈现，关键指标趋势外推"预计 N 天后越限"，预警处置闭环一键转维修工单，ML 模型驱动持续进化
- **能耗与单耗分析**：设备能耗统计与产量单耗（度电/件）趋势对比，白天看不见的电费从这里省
- **设备健康看得见**：状态实时跟踪、OEE 三率现算（区分计划停机）、停机帕累托、保养计划自动生成、**备件台账与领用闭环**（备件领用自动扣库存）、IoT 遥测越限自动开单

## 适用场景

- **整机装配与电子制造**：蓝牙音箱、小家电、消费电子等多工序装配产线，工单进度、报工计件、成品批次一管到底
- **需要批次/序列号追溯的行业**：一键回答"这批不良品用哪批料、哪台机、谁做的"，不良溯源与召回影响范围快速圈定
- **从纸质单据/Excel 升级数字化车间**：开箱即用的平台底座免实施顾问，车间看板 + 工位终端让生产进度实时可见
- **质量体系想落地 8D/SPC 的工厂**：CAPA 纠正预防、SPC 控制图、AQL 抽样、召回清单——体系文件里的要求变成系统里的日常动作
- **想从坏了再修转向预测保养的工厂**：设备健康评分与趋势外推让保养介入走在故障前面
- **已用 GoWind ERP 的工厂**：销售订单自动同步、一键转工单，采购—生产—入库链条自然打通
