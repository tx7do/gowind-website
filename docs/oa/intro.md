# 风行协同办公

风行协同办公是一款面向企业的协同办公系统，覆盖**审批流转、人事考勤、请假报销**等日常办公场景。
系统内置**轻量级工作流引擎**作为审批流转的基础，配套 Web 管理后台与移动端 App，
帮助企业在统一平台上完成申请、审批、打卡与费用管理。

风行协同办公是 GoWind 生态的开源项目，采用 **MIT 协议**开源：源码开放，欢迎试用、反馈与共建，
也欢迎通过文末的联系方式与我们交流。

## 一、核心亮点

### 1. 工作流引擎

- **轻量级审批底座**：内置轻量级工作流引擎，是全系统审批流转的基础；
- **线性状态机**：流程按状态机线性推进，节点流转清晰可控；
- **会签 / 或签**：节点支持会签（全部通过才放行）与或签（任一人通过即放行）；
- **审批撤回**：申请人可撤回尚未走完的流程，误提交可及时纠正；
- **可视化流程编辑器**：流程以可视化方式设计与调整，降低流程维护门槛。

### 2. 审批中心

- **待办集中处理**：所有需要我处理的审批集中在待办列表，逐件清办不遗漏；
- **转办协作**：审批人可将单据转办给其他同事处理，人不在岗流程不断；
- **全程留痕**：每笔单据的提交、通过、驳回、转办全程留痕，随时可追溯。

### 3. 考勤管理

- **GPS + WiFi 围栏打卡**：移动端打卡结合 GPS 定位与 WiFi 围栏双重校验，位置真实可信；
- **定时结算**：考勤数据按周期定时结算，月度统计自动化，减少人工核对。

### 4. 请假管理

- **额度管理**：假期额度统一管理，余额清晰可见，超额请假自动拦截；
- **半日粒度**：请假支持半天为最小单位，贴合实际休假习惯。

### 5. 报销管理

- **发票拍照直传**：移动端拍照上传发票，报销材料随手提交，无需粘贴扫描；
- **流程化审批**：报销单走统一审批流，进度实时可查。

### 6. 四类事务单据

- **出差单**：出差申请与行程报备线上化；
- **加班单**：加班申请登记，与考勤数据呼应；
- **用印单**：印章使用申请与登记，用印有据可查；
- **外出单**：外出申请报备，去向清晰。

### 7. 站内信与公告

- **SSE 实时推送**：审批待办、流程状态变化通过 SSE 实时推送到端，处理不延迟；
- **企业公告**：管理员发布企业公告，重要通知全员触达。

### 8. 企业通讯录

- **组织架构清晰**：按组织架构浏览同事信息，找人高效；
- **信息脱敏**：手机号等敏感信息脱敏展示，保护员工隐私。

### 9. 动态表单引擎

- **表单随流程配置**：申请表单基于动态表单引擎渲染，字段随单据类型灵活定义；
- **业务变化快响应**：新增或调整单据字段以配置方式完成，无需改动代码。

## 四、适用场景

### 企业日常审批线上化

把散落在纸面与群聊中的申请统一搬到线上：

- 出差、加班、用印、外出等事务单据走统一审批流；
- 流程节点按企业管理制度自行设计与调整；
- 审批全程留痕，事后可追溯、可审计。

### 人事考勤与假期管理

以真实位置数据支撑考勤与休假管理：

- 外勤、现场办公人员 GPS + WiFi 围栏打卡，杜绝代打卡；
- 假期额度统一管理，半日粒度请假贴合人事制度；
- 考勤数据定时结算，月度统计自动化。

### 费用报销闭环

报销材料电子化流转，进度随时可查：

- 员工在移动端拍照上传发票，随时随地提交报销；
- 报销单进入统一审批流，财务处理有据可依。

## 五、技术栈与部署

后端基于 go-kratos 微服务框架构建，数据访问层采用 Ent ORM，业务数据由 PostgreSQL 存储；
管理后台基于 Vue3 与 Element Plus 构建，移动端使用 Flutter 开发，覆盖 Android 与 iOS。
本地部署通过 docker-compose 一键拉起 PostgreSQL、Redis、MinIO、etcd、Jaeger 等中间件；
业务服务按端拆分为管理后台 BFF 与移动端 BFF 两组入口，并各自配套 SSE 推送端口。

| 组件 | 说明 |
| --- | --- |
| 后端 | go-kratos + Ent + PostgreSQL，微服务架构 |
| 管理后台 | Vue3 + Element Plus |
| 移动端 | Flutter |
| 中间件 | PostgreSQL / Redis / MinIO / etcd / Jaeger，docker-compose 一键启动 |
| 服务端口 | Admin BFF `:6600`（SSE `:6601`）；App BFF `:6700`（SSE `:6701`） |
