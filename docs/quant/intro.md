# GoWind Quant（风行量化）

GoWind Quant 是一套覆盖「**行情数据 → 智能选股 → 策略研究 → 回测验证 → 模拟交易**」全流程的量化研究平台。行情、数据、研究、交易演练与 AI 助手收进同一个工作台，让策略研究像使用一款专业行情终端一样顺畅。

## 核心亮点

- **数据一步到位**：行情报价、K 线、盘口深度、逐笔成交一屏尽览，实时刷新，盘口异动即刻可见
- **AI 全程参与**：AI 选股、AI 策略生成、AI 回测解读、AI 交易日报——自然语言贯穿研究全流程
- **贴近真实的回测**：考虑涨跌停、停牌等真实交易约束，内置滑点与手续费模型，回测结果更可信
- **组合策略一等公民**：单标的与多标的组合共用一套工作台——股票池圈定标的，截面回调写组合逻辑，组合层面风控与评估
- **稳健性检验内建**：参数寻优、walk-forward 检验、蒙特卡洛置信区间，过拟合防护开箱即用
- **风控演练放心**：限价单、止损单、日内亏损熔断、每日对账修正，模拟交易全链路风险可控
- **数据可信可查**：多数据源交叉接入，数据质量面板逐域展示新鲜度与覆盖率，每一根 K 线可溯源

## 功能全景

### 1. 行情与数据

| 功能 | 说明 |
|---|---|
| 实时行情 | 行情报价、K 线、盘口深度、逐笔成交、指数行情多页签一屏切换 |
| 盘口实时推送 | 盘口与逐笔数据实时刷新，无需手动轮询 |
| 多源数据接入 | baostock、tushare、finnhub、eodhd、marketstack 等主流数据源多路接入 |
| 数据质量面板 | 七个数据域的新鲜度分档、覆盖率、异常检测、多源交叉验证与摄入统计，数据可信度一目了然 |
| 数据源健康监控 | 各数据源可用性与采集状态集中展示，异常早发现 |

### 2. 新闻舆情

| 功能 | 说明 |
|---|---|
| 舆情采集与情感分析 | 市场新闻自动采集，情感倾向自动分析 |
| 相似新闻聚合 | 同一事件的重复报道自动归并，去噪留痕 |
| 舆情告警外发 | 重点舆情即时推送至钉钉、飞书、企业微信群 |
| AI 交易日报 | 每日复盘由 AI 自动生成并主动送达 |

### 3. 智能选股

| 功能 | 说明 |
|---|---|
| 条件选股 | 量价 + 基本面共 8 项条件自由组合筛选 |
| AI 选股 | 用自然语言描述选股思路，AI 自动转为筛选条件 |
| 自选股与预警 | 自选股管理，到达目标价位自动提醒 |
| 定时选股 | 选股方案定时执行，开盘前自动出结果，命中/跌出主动通知 |

### 4. 策略研究

| 功能 | 说明 |
|---|---|
| 策略编写 | 支持 Lua、JavaScript 双引擎，内置 MACD、RSI、BOLL、ATR、KDJ 等常用指标；单标的与多标的组合双形态 |
| 组合策略 | 多标的截面策略：on_bars 截面回调一次拿到全池行情，按指数成分或自定义股票池圈定标的，组合层面风控（如同持仓数上限）与统一评估，回测与实盘演练同引擎 |
| 新闻事件策略 | 订阅新闻告警事件驱动策略执行——行情之外多一种触发源 |
| 因子体系 | 16 个经典因子开箱即用，配套 IC/IR 分析与分层回测，支持自定义因子表达式 |
| AI 策略生成 | 用自然语言描述策略思路，AI 生成策略草稿并自动校验后投入使用 |
| Python 研究 SDK | 研究数据可导出为 pandas 数据表，无缝衔接既有分析环境 |

### 5. 回测中心

| 功能 | 说明 |
|---|---|
| 贴近真实的撮合 | 复权处理、基准对比，并考虑涨跌停与停牌等市场约束 |
| 参数寻优 | 参数网格批量扫参、walk-forward 滚动检验、寻优热力图可视化 |
| 稳健性评估 | 蒙特卡洛置信区间与尾部风险分析，检验策略鲁棒性 |
| AI 回测解读 | 回测报告由 AI 自动解读，快速定位问题 |
| 组合回测 | 多标的组合回测，组合层面风控与统一评估；组合策略同样支持参数网格与 walk-forward 寻优，曲线页可分标的归因 |

### 6. 模拟交易

| 功能 | 说明 |
|---|---|
| 交易工作台 | 下单、持仓、资金一屏操作 |
| 订单类型 | 限价单、止损单，挂单当日有效、收盘自动撤销 |
| 风控熔断 | 内置风控规则与熔断机制，异常自动截停 |
| 每日对账 | 自动对账与差异修正，账实一致 |
| 组合总览 | 多策略组合的资金与收益总览，集中度一目了然 |

### 7. AI 助手

| 功能 | 说明 |
|---|---|
| 智能问答 | 基于平台数据与研究知识的对话问答，支持挂载知识库 |
| 智能问数 | 用自然语言查询研究数据，不写查询语句也能取数 |
| 定时问数 | 常用问数任务定时执行，结果主动推送 |

## 适用场景

- **投资研究团队**：统一的数据、选股、回测与复盘工作台，替代零散工具拼凑
- **策略研究者**：从想法到验证的完整链路，AI 辅助加速策略迭代
- **多标的/组合策略研究者**：截面策略一次评估一篮子标的，组合层面风控与归因
- **量化教学与实训**：真实市场约束下的模拟交易环境，练手不碰真金
