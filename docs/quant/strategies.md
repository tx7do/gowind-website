# 策略研究

> 本页面介绍 GoWind Quant 支持的四类策略研究范式，以及平台为每一类提供的研究支撑。所有内容面向研究者视角，不涉及具体策略参数与任何业绩数据。

策略研究的起点是一个想法：「行情走强时跟进能不能赚钱？」「两只走势高度相关的股票价差拉大后会不会回归？」GoWind Quant 把从想法到结论的路径产品化：**想法 → 规则化 → 回测验证 → 稳健性检验 → 模拟演练**，每一步都有对应的工作台。

## 一、四类策略范式

### 1. 趋势跟随

**核心思路**：识别市场方向，顺势持有，用止损控制判断错误的代价。

| 常见研究难点 | 平台支撑 |
|---|---|
| 日线出信号、分钟线找进场点，多周期来回切换 | 多周期行情同屏对照，历史数据自动对齐 |
| 止损假设过于理想，验证结果失真 | 回测内置滑点模型与真实成交约束 |
| 品种多、资金怎么分 | 组合策略引擎：股票池圈定标的，截面回调一次处理全池，组合层面风控与统一评估 |

### 2. 统计套利

**核心思路**：找到走势高度关联的品种对，当价差偏离历史规律时下注回归。

| 常见研究难点 | 平台支撑 |
|---|---|
| 关联关系会失效，怎么发现 | 均值回归指标与状态监控，关系断裂自动告警 |
| 价差偏离多少才算「足够」 | 统计指标（如 Z-Score）内置计算，阈值参数化 |
| 两腿下单节奏不一致 | 组合回测按同一时间轴推进，还原真实节奏 |

### 3. 做市策略

**核心思路**：同时提供买价与卖价，赚取买卖价差，核心是库存管理与报价节奏。

| 常见研究难点 | 平台支撑 |
|---|---|
| 订单簿变化太快，看不过来 | 盘口深度与逐笔成交实时推送，高频画面无延迟 |
| 库存堆积是主要风险 | 模拟交易工作台实时展示持仓与资金，风控规则可配置 |
| 报价策略对延迟敏感 | 事件级回测引擎，逐笔还原市场节奏 |

### 4. 机器学习

**核心思路**：用模型从历史数据中学习规律，输出买卖信号。

| 常见研究难点 | 平台支撑 |
|---|---|
| 模型「记住」了历史，换段数据就失效 | walk-forward 滚动检验 + 蒙特卡洛置换检验 |
| 因子太多，不知道哪些有效 | 16 个经典因子 + IC/IR 分析 + 分层回测 |
| 从模型到策略的工程衔接 | AI 策略生成把研究结论转成可回测的策略草稿 |

## 二、从想法到结论：一次完整的研究旅程

1. **提出想法** —— 在数据面板观察行情规律，用 AI 助手查数据验证直觉；
2. **规则化** —— 用策略脚本（单标的或组合形态）或 AI 策略生成，把想法变成可执行的规则；
3. **快速回测** —— 先跑基础回测看大方向，AI 解读快速定位明显问题；
4. **参数寻优** —— 网格扫参 + 热力图，观察参数敏感度而非只看最优点；
5. **稳健性检验** —— walk-forward 检验、蒙特卡洛置信区间，过滤「过拟合」参数；
6. **模拟演练** —— 进入模拟交易工作台，带风控规则实盘节奏演练；
7. **每日复盘** —— AI 交易日报自动总结，舆情与数据质量变化一并纳入。

## 三、防自欺：为什么稳健性检验是标配

回测里最贵的教训是「只有回测好看」。平台把三类防护做成了默认流程，而不是可选项：

- **样本外检验（walk-forward）**：滚动地「用一段训练、用下一段验证」，拒绝只在特定区间有效的参数；
- **随机对照（蒙特卡洛置换）**：打乱信号时序，评估收益是否真的优于随机；
- **参数稳定曲面（寻优热力图）**：真正稳健的策略在最优参数附近表现平滑；尖锐的「最优点」通常是过拟合。

::: tip 研究纪律
平台不提供任何投资建议，也不展示任何实盘业绩；所有研究与演练均基于历史数据与模拟环境。
:::
