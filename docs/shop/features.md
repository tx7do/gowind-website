# GoWind Shop 功能手册

本手册面向电商运营者，按业务域介绍 GoWind Shop 的各项功能，帮助你快速了解平台能做什么、
运营团队的日常工作可以在哪些模块中完成。

## 一、商品管理

### 商品与类目

| 功能 | 说明 |
| --- | --- |
| 商品发布与上下架 | 商品与 SKU 级别的发布管理，随时上下架控制售卖 |
| 属性管理 | 维护商品属性，规范商品信息结构 |
| 树形类目 | 多级类目树，支撑复杂商品分类体系 |
| 品牌管理 | 统一维护商品品牌信息 |
| SKU 定价 | 按 SKU 粒度设定价格，支撑差异化售卖 |

### 商品内容编辑

- **CMS 范式编辑**：商品编辑采用 CMS 范式，像编排内容一样编排商品详情
- **富文本详情**：商品详情支持富文本编辑，承载图文并茂的商品介绍
- **翻译页签**：商品编辑内置翻译页签，可按语言逐份维护多语言内容

### 商品搜索（买家侧）

- **全文检索**：基于 OpenSearch 的商品全文检索，搜索结果精准
- **输入联想**：搜索框输入即联想，降低买家的输入成本
- **AI 查询改写**：自然语言搜索自动改写为检索关键词，口语化描述也能命中商品
- **周期全量重索引**：系统周期性执行全量重索引，保证搜索结果与商品数据一致

## 二、订单与自动化

### 购物与下单

| 功能 | 说明 |
| --- | --- |
| 购物车 | 买家跨商品加购、统一结算 |
| 订单状态机 | 订单按状态机规范流转，状态清晰、可追溯 |
| 乐观并发控制 | 订单操作采用乐观并发控制，避免并发修改引发数据冲突 |

### 订单自动化

- **超时未付自动取消**：订单超时未支付，系统自动取消，释放库存等占用资源
- **发货超期自动确认收货**：发货后超期未确认，系统自动确认收货，避免订单长期挂起
- **物流发货联动**：物流发货与订单状态机联动，发货即同步订单状态

### 订单通知

- **全链路站内信**：从下单到售后完成，订单全链路关键节点均通过站内信通知买家

::: tip 状态一目了然
管理后台全模块的状态列均以彩色标签（tag）呈现，运营人员扫一眼即可分辨订单与各项业务数据的状态。
:::

## 三、营销促销

### 促销玩法

| 玩法 | 规则要点 |
| --- | --- |
| 商品专价 | 针对指定商品设置专属价格 |
| 店铺满减 | 店铺维度的满额减现活动 |
| 秒杀 | 限时抢购；行锁防超卖，支持限购 |
| 拼团 | N 人成团；到期未成团自动退款并关闭 |

### 统一计价优先级

同一商品同时命中多种促销时，按以下优先级取价：

| 优先级 | 价格类型 | 说明 |
| :---: | --- | --- |
| 1（最高） | 拼团价 | 命中拼团活动时按拼团价计 |
| 2 | 秒杀价 | 命中秒杀活动时按秒杀价计 |
| 3 | 商品专价 | 命中专价商品时按专价计 |
| 4（基础） | 商品原价 | 以上促销均未命中时按 SKU 原价计 |

::: tip 优惠叠加封顶
促销价与优惠券可以叠加享受，但叠加优惠设有封顶，避免叠加后过度让利，促销成本可控。
:::

## 四、优惠券与会员积分

### 优惠券

- **模板创建**：运营通过优惠券模板批量创建券活动
- **用户领券**：优惠券发放至用户账户
- **下单核销**：下单时核销抵扣
- **退款返还**：发生退款时优惠券自动返还，保障买家权益

### 会员积分

- **消费入账**：消费即按规则入账积分
- **等级倍率**：会员等级越高，消费获得的积分倍率越高
- **签到得积分**：买家每日签到可获得积分
- **积分兑换券**：积分可兑换优惠券，促进复购
- **append-only 台账**：积分全程流水化记账、只增不改，每一笔都可追溯

### 会员等级

- **自动分层**：按会员累计支付金额自动分层，无需人工干预
- **权益联动**：等级决定积分倍率，刺激持续消费

## 五、售后与库存

### 售后退款

售后流程全自动闭环：

**买家发起售后 → 商家审批 → 渠道退款 → 库存回补 → 站内信通知 → 积分回冲**

- **买家侧**：发起售后后各节点自动推进，进度透明可感知
- **运营侧**：仅需处理审批环节，后续动作由系统自动完成

### 库存管理

- **append-only 操作流水**：所有库存操作均记录为只增不改的操作流水
- **全程审计**：每一笔库存增减都可追溯操作来源，盘点与对账有据可依

## 六、支付与财务

### 支付渠道

| 渠道 | 适用场景 |
| --- | --- |
| 微信支付 Native | PC 端扫码支付 |
| 微信支付 H5 | 移动端拉起微信支付 |
| 支付宝 | 主流移动与 PC 支付 |
| 模拟支付 | 内置模拟渠道，用于演示与联调，不发生真实资金流转 |

### 支付可靠性

- **两段式支付**：支付意图与支付回调两段式设计，支付状态可靠
- **对账自愈**：支付对账具备自愈能力，异常状态自动修复
- **退款漂移检测**：自动检测退款的异常漂移，及时暴露问题
- **关单联动**：订单关闭时联动失效旧支付二维码，避免过期二维码被扫码支付引发错账

### 资金与合规

::: warning 商户资质
支付商户资质由部署方自行持有，货款直接进入部署方商户账户，平台不经手资金。
:::

### 财务工具

| 功能 | 说明 |
| --- | --- |
| XLSX 对账导出 | 财务数据一键导出 XLSX，便于线下对账 |
| 发票 | 支撑订单开票流程 |
| 税率规则 | 可配置税率规则，适配不同地区税务要求 |
| 运费模板 | 模板化运费配置，按规则自动计算运费 |

## 七、内容与评论

### 商品评论

- **树形评论**：评论支持树形回复，讨论脉络清晰
- **点赞互动**：买家可对评论点赞
- **商家回复**：商家可回复评论，公开处理买家反馈
- **AI 反垃圾**：AI 自动识别过滤垃圾评论，减轻人工审核负担

## 八、AI 导购

C 端店铺前台内置 AI 导购悬浮助手，买家以自然语言对话即可完成购物决策：

| 能力 | 说明 |
| --- | --- |
| 找商品 | 根据描述推荐匹配商品 |
| 查价格 | 查询商品当前售价与促销价 |
| 查订单 | 查询买家订单状态 |
| 查优惠 | 查询可用优惠券与进行中的优惠活动 |

AI 导购通过工具循环依次调用上述能力，直到给出完整答复；
配合搜索的 AI 查询改写，自然语言能力贯穿买家浏览、搜索到售后的全流程。

## 九、系统管理

| 功能 | 说明 |
| --- | --- |
| 多租户 | 一套系统支撑多租户并行运营 |
| RBAC 权限 | 基于角色的访问控制，运营团队按角色授权 |
| 多语言字典 | 界面与内容多语言统一维护 |
| 任务调度 | 促销、自动化等周期与定时任务统一调度 |
| 审计日志 | 记录登录、操作、权限变更与数据访问，安全可追溯 |
| 邮箱找回密码 | 支持通过邮箱找回密码 |
| 登录策略 | 可配置登录安全策略 |
| 站内消息 | 面向买家的站内消息触达 |

::: tip 后台使用体验
管理后台支持暗色主题，全模块状态列以彩色标签呈现，长时间运营作业更舒适、状态识别更高效。
:::
