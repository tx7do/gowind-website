# GoWind Shop 产品介绍

GoWind Shop 是一款面向出海场景的企业级多语言电商平台，采用 **API 优先、前后端分离**的架构设计，
原生支持**多语言内容分发**与**多币种商品展示**，帮助企业快速搭建面向全球消费者的品牌商城，
并提供私有化部署能力。

GoWind Shop 是 **GoWind 生态的开源项目**：源码开放，欢迎试用、反馈与共建；
同时提供私有化部署与技术支持服务，如需合作请通过文末的联系方式与我们沟通。

## 一、产品定位

| 维度 | 说明 |
| --- | --- |

## 二、核心亮点

### 1. 为出海而生：多语言与多币种

- **多语言原生内容分发**：商品、类目等内容以多语言为一等公民进行管理，前台按访客语言自动呈现
- **多币种商品展示**：商品价格支持多币种展示，贴合不同地区消费者的浏览习惯
- **单一结算币种**：展示多币种、结算单一币种，运营与财务对账简单清晰
- **移动端适配**：店铺前台针对移动端深度适配，并提供吸底导航

### 2. 灵活强大的促销引擎

- **多种促销玩法**：商品专价、店铺满减、秒杀、拼团一站配齐
- **秒杀防超卖**：秒杀活动采用行锁防超卖机制，并支持限购
- **拼团自动化**：支持 N 人成团，到期未成团自动退款并关闭活动
- **统一计价**：拼团、秒杀、专价统一计价优先级，与优惠券叠加享受并设有封顶，让利可控

### 3. 稳健的支付与对账

- **主流支付渠道**：支持微信支付（Native / H5）与支付宝
- **两段式支付**：支付意图与支付回调两段式设计，支付状态可靠
- **对账自愈**：支付对账具备自愈能力，减少人工介入
- **退款漂移检测**：自动检测退款异常漂移，保障资金安全
- **资金隔离**：部署方自带商户资质收款，平台不经手资金

### 4. AI 导购助手

- **对话式导购**：C 端悬浮助手，买家以自然语言提问即可获得购物建议
- **能力闭环**：支持找商品、查价格、查订单、查优惠等工具循环调用
- **智能搜索**：AI 查询改写将自然语言自动转换为检索关键词，提升搜索命中率

### 5. 全流程自动化的订单与售后

- **订单自动化**：超时未付自动取消订单，发货超期自动确认收货
- **售后全自动**：买家发起售后，经审批后自动完成渠道退款、库存回补、积分回冲并站内信通知
- **全链路通知**：订单全链路关键节点通过站内信通知买家，状态变化即时可知

## 三、功能全景

| 功能域 | 主要能力 |
| --- | --- |
| 商品与交易 | 商品 / SKU 发布上下架，属性、树形类目、品牌管理，SKU 定价，购物车，全文检索与输入联想 |
| 订单与自动化 | 订单状态机，超时未付自动取消，发货超期自动确认收货，订单全链路站内信通知 |
| 营销促销 | 商品专价、店铺满减、秒杀（防超卖 + 限购）、拼团（N 人成团、到期自动退款关闭），统一计价优先级 |

| 交易保障 | 售后退款全自动闭环，库存操作流水审计，物流发货状态机联动，XLSX 财务对账导出、发票、税率规则、运费模板 |
| 支付 | 微信支付 Native / H5、支付宝；两段式支付、对账自愈、退款漂移检测、关单联动 |
| AI 能力 | AI 导购助手（找商品 / 查价格 / 查订单 / 查优惠），搜索 AI 查询改写，评论 AI 反垃圾 |
| 平台能力 | 多租户、RBAC 权限、多语言字典、任务调度、审计日志、邮箱找回密码、登录策略、站内消息 |

各功能域的详细说明请参阅 [功能手册](/shop/features.md)。

## 五、适用场景

### 品牌出海

面向海外消费者的品牌自营商城：

- 多语言呈现品牌与商品内容，多币种展示价格、单一币种结算
- 促销引擎与会员体系配合，完成从拉新到复购的运营闭环
- 私有化部署，业务数据自主可控

### 多语言商城

一套后台运营多语言商品内容：

- 内容多语言原生分发，无需为每种语言单独建站
- 商品编辑提供翻译页签，运营可逐语言维护商品详情
- 前台按访客语言自动呈现，浏览体验本地化

### 私域电商

搭建自有用户池的私域运营阵地：

- 优惠券、会员积分、秒杀、拼团等玩法促进转化与复购
- 站内消息触达买家，订单全链路通知
- 多租户能力支持多品牌、多业务线并行运营，互不干扰

## 六、技术架构

GoWind Shop 后端基于 go-kratos 微服务框架构建，以 Protobuf 契约驱动服务设计与实现；
数据层采用 PostgreSQL 承载业务数据、OpenSearch 提供全文检索、Redis 承担高速缓存。
管理后台基于 Vue3 与 Element Plus 构建；店铺前台基于 Nuxt 静态站点生成（SSG）交付，
共 20 个页面，支持亮暗双主题、移动端适配与多语言。
产品通过 Docker Compose 部署，由 nginx 提供同源 HTTPS 反向代理，并使用 PM2 托管应用进程。
