# GoWind Shop 在线体验

GoWind Shop 提供两个在线演示站点，无需本地部署即可完整体验买家购物与运营管理的核心流程。

## 演示站点

| 站点 | 地址 | 视角 |
| --- | --- | --- |
| 店铺前台 | <https://shop.gowind.cloud> | 买家视角：浏览、下单、订单、消息 |
| 管理后台 | <https://admin.shop.gowind.cloud> | 运营视角：促销、订单、库存 |

::: warning 演示环境须知
- 演示站数据会**定期重置**，您创建的订单、优惠券等数据可能随时被清除，请勿在演示环境存放任何重要数据。
- **演示账号未公开**，请通过微信联系 `yang_lin_bo`（备注 **go-wind-shop**）或发邮件至 <yanglinbo@gmail.com> 获取。
:::

## 体验路线一：店铺前台（买家视角）

建议按以下路线完整走通一次购物流程：

### 第 1 步：浏览首页与商品分类

打开 [店铺前台](https://shop.gowind.cloud) 首页，浏览首页布局与商品分类入口。
页面支持亮暗双主题与多语言切换，移动端访问时可通过底部吸底导航快速切换页面。

![店铺前台首页](/assets/images/shop/app-home.png)

### 第 2 步：查看商品与拼团价

从分类进入商品详情页，重点关注参与拼团、秒杀活动商品的促销价格展示，
感受统一计价优先级下的实际售价。

![商品促销详情](/assets/images/shop/app-product-promo.png)

### 第 3 步：加入购物车并下单

选择商品规格加入购物车，按页面提示完成一次下单。
平台内置模拟支付渠道，整个流程不会产生真实资金流转。

### 第 4 步：查看我的订单

进入「我的订单」，查看刚创建的订单与状态流转。

![我的订单](/assets/images/shop/app-orders.png)

### 第 5 步：接收消息通知

订单全链路的关键节点都会通过站内信通知买家，打开消息中心查看订单通知。

![站内消息](/assets/images/shop/app-messages.png)

::: tip 别忘了切换主题与语言
店铺前台支持亮暗双主题与多语言切换，走完购物流程后不妨各切换一次，
感受多语言内容分发与暗色主题下的浏览体验。
:::

## 体验路线二：管理后台（运营视角）

使用获取到的演示账号登录 [管理后台](https://admin.shop.gowind.cloud)，建议依次查看：

### 1. 促销活动

查看促销活动管理页面，了解秒杀、拼团等活动的配置方式与活动状态。

![促销活动管理](/assets/images/shop/admin-promotions.png)

### 2. 订单管理

查看订单列表与状态标签，体验订单状态机的可视化呈现；
全模块状态列均以彩色标签展示，便于快速筛选与定位。

![订单管理](/assets/images/shop/admin-orders.png)

### 3. 库存流水

查看库存操作流水，所有库存增减均以 append-only 流水记录，可逐笔追溯。

![库存操作流水](/assets/images/shop/admin-stock-op-logs.png)

::: tip 更多模块
除上述三个模块外，演示后台还开放了商品、优惠券、会员等模块，
可结合 [功能手册](/shop/features.md) 逐项对照体验。
:::
