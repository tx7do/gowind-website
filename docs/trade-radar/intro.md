# GoWind Trade Radar（外贸选品雷达）

GoWind Trade Radar 是面向外贸出口与跨境电商团队的「选品量化大脑」：用客观的搜索趋势、平台榜单、竞品评价与供应链价格数据，**算出**海外市场的下一个爆款品类、差异化卖点和入场窗口——把「跟着感觉选品、拍脑袋定款」变成一次可验证的数据决策。

需求、竞争、成本三侧数据汇成小时级「商品 K 线」，十类选品信号自动扫描、多渠道推送；每一个信号策略都先经过历史数据回测验证，再投入日常使用；机会评分卡、选品沙盘与项目跟进把信号一路落到「做哪几个品、各投多少、何时启动」。

> 与 GoWind Quant（量化研究）同一产品范式：「采集 → 数据底座 → 信号 → 回测 → 决策 → 反馈闭环」，从证券市场延伸到外贸选品场景。

## 核心亮点

- **三侧数据，客观算品**：需求侧（搜索/新闻/视频/社区声量）、竞争侧（榜单/价格/评论/卖家）、成本侧（1688 货源/汇率/海运运价）同池入库，小时级聚合
- **十类信号，覆盖选品全判断**：从「谁开始被搜」到「能不能卖」「AI 有没有推荐你」，每一类信号回答一个具体问题
- **先回测，再使用**：动能/套利/骤降/毒药四策略参数网格回测，命中率与兑现倍数先行验证；信号自动结算兑现标签，与人工标注双真值
- **从信号到立项一条线**：机会评分卡 → 选品沙盘 → 一键立项 → 七阶段项目跟进 → 结项冻结复盘，生意口径的闭环
- **AI 原生**：AI 可见度探测器测「海外买家问 AI 时有没有你」，GEO 内容工坊生成「让 AI 推荐你」的英文内容；22 个 MCP tools 让 Claude/Cursor 等 AI 客户端直查雷达数据
- **越用越准**：信号标注 → 准确率统计 → 实体可信度排行 → 调参有据，反馈闭环内建

## 功能全景

### 1. 情报采集

| 功能 | 说明 |
|---|---|
| 需求侧数据源 | Google Trends 兴趣指数、Google News 行业声量、YouTube 测评/开箱热度、HackerNews 出海圈讨论、Wikipedia 品类浏览量——免凭证开箱可用 |
| 竞争侧数据源 | Amazon BSR 热销榜/商品价格/评论流、速卖通热销、eBay 趋势、TikTok 电商标签热度——统一走可插拔合规端点（自建合规采集服务或数据供应商） |
| 成本侧数据源 | 1688 货源数/MOQ/出厂价、日频汇率（免凭证）、海运运价指数 |
| AI 答案探测器 | 以海外买家口吻向大模型批量提问（品类级 + 品牌级问题集），测「AI 推荐谁、排第几、口碑如何」，随探测收割推荐名单上的竞品线索 |
| 选品清单页面化管理 | 监控哪些商品/关键词自己登记——每个实体挂跨平台足迹（Amazon ASIN/速卖通/eBay/1688/TikTok），保存即生效；排除词治理关键词歧义 |
| 发现扫描 | 60+ 品类词根库全量声量扫描，无需配置即可出「萌芽词榜」，看中即认领进选品清单 |
| 采集源运维 | 每个源的健康状态、最近成功时间与新鲜度徽章，连续失效自动告警 |

### 2. 数据底座

| 功能 | 说明 |
|---|---|
| 小时级「商品 K 线」 | 原始数据校验/归一/小时聚合，产出三组指标时序：需求（搜索兴趣/声量/销量估计/榜位）、竞争（评论存量/好评率/卖家数/广告在投）、成本（价格/折扣/货源数/汇率/运价） |
| 长期保留 | 聚合时序长期保存，回测与复盘始终有历史可依 |

### 3. 十类信号（自动扫描 + 多渠道推送）

| 信号 | 回答的问题 |
|---|---|
| 需求动能 MOMENTUM | 谁开始被搜/被讨论了 |
| 价差套利 ARBITRAGE | 1688 出厂价 × 平台售价，利差够不够 |
| 竞品痛点 PAIN_POINT | 买家在骂什么 |
| 趋势预测 TREND | 6-12 个月后这个品类会怎样 |
| 竞品骤降 DOWNSWING | 谁在掉链子，留下份额真空 |
| 红海毒药 UA_POISON | 哪个品类在打价格战，虚火别跟 |
| 巨头虹吸 BLACKHOLE | 头部大卖/平台自营何时入场 |
| 跨市场迁移 MIGRATION | 下一个该盯哪个市场 |
| 合规预警 COMPLIANCE | 能不能卖（召回/认证红线） |
| AI 可见度 AI_VISIBILITY | 海外买家问 AI 时有没有你 |

信号统一落盘去重，推送飞书 / 钉钉（可加签）/ Slack / Telegram / 邮件 / webhook，页面化渠道管理、按种类与级别路由。

### 4. 验证深潜

| 功能 | 说明 |
|---|---|
| 回测调参 | 动能/骤降/套利/毒药四策略 × 9 组参数网格热力图，命中率 + 兑现倍数 P50/P90，支持按品类分层——策略先验证再使用 |
| 兑现自动结算 | T+N 后自动按指标口径给信号打兑现标签，与人工标注双真值 |
| 竞品痛点报告 | 差评聚类（痛点指数/占比/典型原话/差异化卖点） |
| 卖点下钻（AI） | 一键提炼竞品的核心卖点图谱、买家情绪与跟随策略——痛点告诉你买家骂什么，卖点告诉你爆款为什么成 |
| AI Listing 生成 | 评论证据链（差评避坑 + 好评卖点）→ 标题/五点描述/后台搜索词草稿，附证据溯源与合规提醒 |
| 广告测款 | 立项前低预算广告验证需求真实性：AI 测款 brief → Meta/TikTok 一键代投 → 48h CTR 自动对照 |

### 5. 决策输出

| 功能 | 说明 |
|---|---|
| 机会评分卡 | 痛点 × 骤降 × 套利联合打分（0-100 窗口分），横向排期依据 |
| 选品沙盘 | 输入总预算与规划期，自动产出「做哪几个品、各投多少、何时启动」——红海毒药一票排除、同类目上限、上架错峰、预算 80-20 分配，按沙盘一键立项 |
| 项目跟进 | 立项 → 测款 → 寻源 → 首单 → 上架 → 复盘/搁置七阶段生命周期，结项冻结把证据快照固化成不可变记录 |
| 今日行动清单 | 新信号、预警触发中、备货临期、测款待处置、项目停滞等七类待办聚成一列，仪表盘置顶 |
| 备货时钟 | 品类旺季起点倒扣生产 + 头程周期 = 最晚下单日，临期/超线到点提醒 |
| 决策周报 | 评分卡 TOP/竞争态势/痛点动态/AI 推荐位/项目进展/备货时钟一报打尽，置顶 AI 编者按（选品总监人格）：本周【立刻上】谁、【别碰】谁 |

### 7. 反馈闭环

## 适用场景

- **外贸出口/跨境电商团队**：选品从拍脑袋到看数据，十类信号 + 沙盘排期一条线
- **工厂/供应链转型出海**：出厂价是自己的强项数据，先算清价差利再开模
- **品牌出海团队**：经营「AI 推荐位」——监测自家与竞品的 AI 可见度，用 GEO 内容工坊持续改进
- **选品服务机构**：多品类发现扫描 + 评分卡排期 + 项目跟进，形成选品流水线
