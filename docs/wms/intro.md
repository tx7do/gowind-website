# GoWind WMS 产品介绍

GoWind WMS 是一款面向**中小 3PL 仓、电商仓、工厂成品仓**的企业级开源仓储管理系统（WMS），
原生支持**多货主**与**库位级**库存管理，库存引擎借鉴 Odoo 的 stock.quant / picking / move 建模思想。

GoWind WMS 由 GoWind ERP 的库存模块衍生而来，与 ERP 同栈同源，采用 **MIT 协议**开源，
欢迎试用、反馈与共建；如需私有化部署与技术支持服务，请通过文末的联系方式与我们沟通。

::: tip 版本说明
开源版功能已完整落地，并通过端到端冒烟验收，正式发布准备中；
计费引擎、第三方平台对接等能力规划于商业版。
:::

## 一、核心亮点

### 1. 多货主库存隔离

- **3PL 场景原生支持**：货主作为一等概念建模，同一仓库可服务多个货主
- **数据隔离**：库存与单据按货主隔离，互不可见、互不干扰
- **一仓多货主**：贴合 3PL 仓多客户共仓运营的实际形态

### 2. Odoo 风格库存引擎

- **quant / picking / move 建模**：借鉴 Odoo stock 的成熟模型，库存可追溯、移动有单据
- **批次与效期**：批次管理，FEFO（先到期先出）扣减
- **移动平均成本**：移动平均成本核算，成本随出入库自动滚动

### 3. ASN 到货预约全流程

- **到货预约**：货主提前提交 ASN（到货预约），入库计划先行
- **宣告与收货**：到货现场宣告确认，按预约明细收货、防超收
- **上架建议**：收货后生成上架建议，上架有据可依

### 4. 波次出库

- **出库单直发**：出库单校验通过后可直接下发执行
- **波次合并**：拣货任务按波次合并，批量执行，提升拣货效率
- **波次调试**：提供波次调试视图，执行过程可观察、可排查

### 5. SaaS 订阅与配额护栏

- **订阅管理**：面向 SaaS 化运营的订阅管理能力
- **配额护栏**：用量达到配额自动拦截，资源占用可控
- **审批轨**：关键单据走统一审批轨，全程留痕可查

## 四、适用场景

### 中小 3PL 仓

- 多货主共仓运营，货主数据原生隔离
- ASN 到货预约 + 收货防超收，入库有序不乱
- 库位级管理，储位精确定位、作业路径清晰
- SaaS 订阅与配额护栏，服务多货主更省心

### 电商仓

- 波次出库合并拣货任务，批量执行应对订单高峰
- FEFO 批次效期扣减，先到期先出
- 库龄报表 30 / 60 / 90 / 180+ 分桶，滞销库存一眼可见
- 中英日三语界面，适配跨境电商与出海仓储团队

### 工厂成品仓

- 成品出入库全流程库位级管理
- 库存冻结与出库拦截，异常库存可控
- 跨仓调拨事务原子，多仓账实一致

## 五、技术栈与部署

GoWind WMS 后端基于 **go-kratos** 微服务框架构建，ORM 采用 **Ent**，服务间通信使用 **gRPC**；
管理后台基于 **Vue3** 构建，现场作业配备 **Flutter PDA 扫码端**（适配工业手持终端）。

部署方式与 GoWind ERP 同构：docker-compose 拉起同一套中间件
（PostgreSQL、Redis、MinIO、etcd，绑定 127.0.0.1），
应用侧提供 admin BFF（`:6600`）与 app BFF（`:6700`）两个服务入口。
详细部署步骤见仓库内 `docs/deployment.md` 部署文档。

WMS 的库存建模与部署形态均源自 GoWind ERP，进一步了解参阅 [GoWind ERP 产品介绍](/erp/intro.md)。
